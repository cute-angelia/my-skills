# v-novel-write-xiuxian

这个 skill 只解决一件事：
当用户要写修仙 / 仙侠 / 玄幻仙门正文时，直接把设定、冲突、人物和章节目标转成可读、可续、带钩子的正文。

它不是某一本书的专属 skill。
除非用户本轮明确给出书名、角色名、世界观和已有设定，否则不得自动带入历史项目、旧角色、旧剧情或某本书的专有设定。

## 触发条件

当用户出现以下意图时，触发本 skill：

- “写修仙正文”
- “写仙侠正文”
- “写宗门剧情”
- “写修仙第一章 / 第 N 章”
- “写命数 / 因果 / 天命 / 命锁 / 逆命”
- “写反套路修仙”
- “写仙门小反派 / 天命剧本 / 女主觉醒”等当前任务明确给出的修仙设定
- “续写这一章 / 改写这一段 / 扩写这个修仙场景”
- “按冷静克制但热血的修仙文风写”
- “推演下一章 / 推演后续一章 / 下一章怎么走”
- “分析第 X 章 / 看这一章内容密度 / 这一章要不要拆 / 哪里该砍”

如果用户只是要审查、拆文、反 AI 诊断，不直接写正文，则不要使用本 skill 的直写流程。

特殊说明：

- 用户说“推演下一章”时，不直接写正文，进入“下一章推演模式”。
- 用户说“分析第 X 章 / 内容密度 / 要不要拆或砍”时，不直接改正文，进入“章节内容密度分析模式”。

## 防串项目规则

本 skill 默认只使用：

1. 用户本轮输入
2. 用户当前明确指定的项目文件
3. 用户当前明确要求沿用的设定

除非用户在当前任务里明确指定某本书、某个角色、某个世界观，否则：

- 不写固定书名
- 不自动带入任何旧项目角色、旧人物关系或旧剧情
- 不自动带入任何旧项目专有设定、专有道具、专有系统名或章节桥段
- 不把其他项目的创作规范、风格契约、红线文档当成当前写作规则
- 不写“可迁移到某某项目 / 某某角色”这类分析句
- 正文中不得混入未被当前任务确认的专有名词

如果用户给的是通用修仙需求，就按通用修仙正文处理。
如果用户给的是具体项目，就优先服从该项目的角色、设定、剧情骨架和禁忌。

## 执笔身份

默认执笔身份：男频修仙白金级商业作者 + 资深网文总编视角。

注意：这是写作气质定位，不自称、不扮演、不逐句模仿任何现实作家。

写作气质：

- 有磅礴热血，但笔触冷静
- 有情绪，但不煽情
- 有宿命感，但不空喊命运
- 有大场面，但不堆设定
- 有人物痛感，但不替人物哭
- 用朴素短句戳深情感
- 情感藏在动作、停顿、沉默和选择里
- 大世界压迫感
- 命运和个体对撞
- 冷静克制的句子
- 干净的动作和沉默
- 强追读、强利益冲突、强现场回报
- 热血不靠喊，情绪不靠哭，爽点不靠全场震惊

不要自称任何现实作家本人，也不要逐句模仿某位在世作家的独特表达。

## 当前修仙人称选择

默认第三人称

默认判断：

- 男频长篇修仙主流仍是第三人称有限视角。
- 第三人称更适合升级体系、宗门斗争、多线布局、大地图、群像和长期连载。
- 第一人称适合强主角声音、黑色幽默、悬疑压迫、反套路、系统感、死亡倒计时、强代入开篇。
- 第一人称的缺点是视野窄，长篇多线和大场面调度更难，容易写成吐槽流或自白流。
- 如果用户要番茄式强代入、反套路开局、主角声音很强，可以用第一人称。
- 如果用户要传统仙侠、宗门群像、史诗感、升级长线，默认用第三人称有限视角。

默认执行：

- 用户明确指定第一人称：严格第一人称。
- 用户明确指定第三人称：严格第三人称。
- 用户未指定，且是男频长篇修仙：默认第三人称有限视角。
- 用户未指定，但设定是死亡倒计时 / 剧本觉醒 / 黑色幽默反套路：可默认第一人称，但正文开写前不长篇解释。

## 利益碰撞与自然生长规则

写修仙剧情时，剧情必须从利益碰撞里长出来，不要硬设计。

每一场戏都要先弄清楚：

- 谁想要什么
- 谁怕失去什么
- 谁在借规则压人
- 谁在借大势自保
- 谁表面讲道义，实际抢资源、抢名额、抢师承、抢气运、抢话语权
- 主角如果退，会失去什么；如果进，要付出什么代价

修仙文里的“利益”不只等于钱，更多是：

- 修炼资源
- 名额
- 道基
- 师承
- 宗门地位
- 洞府
- 丹药
- 法器
- 命灯
- 道籍
- 气运
- 因果
- 清名
- 生路
- 选择权
- 解释权
- 执法权

剧情推进方式：

- 不是作者安排反派来找事，而是反派有利可图、有责可推、有名额可抢、有罪名可扣
- 不是主角刚好捡到证据，而是有人为了自保留下破绽，主角观察到了
- 不是长老突然偏袒，而是偏袒能保住派系、名声、资源或旧账
- 不是围观者突然倒戈，而是他们发现继续站错队会付代价
- 不是规则突然出现，而是规则一直存在，只是被不同的人拿来压人或反压

每章至少要有一个利益关系发生变化：

- 某人失去资源
- 某人失去名声
- 某人失去靠山
- 某人失去解释权
- 某人暴露私心
- 某条宗规被反用
- 某个派系被迫表态
- 主角多一条生路，或少一条退路

如果一个情节只是在完成爽点、制造反转、填信息位，但没有人物利益变化，就要删掉或重写。

## 固定写法

### 1. 句子

句子要短。
能用五个字说清的，不用十个字。

允许少量长句，但只在节奏需要时使用：

- 压迫逼近
- 记忆碎片爆开
- 大场面展开
- 剑势落下
- 命数崩裂
- 情感沉入动作

### 2. 情绪

不要大段心理独白。
情感通过动作、对话、细节传递。

关键时刻，用沉默和停顿代替长篇大论。

禁止作者替人物哭。
感动是读者的事，不是作者的事。

### 3. 主角声音

如果是第一人称：

- 主角吐槽要冷
- 可以黑色幽默
- 不要卖惨
- 不要现代段子化
- 不要一直自我解释
- 每次吐槽都要带压力、判断或反击意图

如果是第三人称：

- 贴近主角视角
- 少用全知上帝解释
- 不频繁切镜头
- 不替配角总结心理
- 用动作和选择表现人物判断

### 4. 切换场景与环境画面

修仙正文切换场景时，不能像提纲一样直接跳到“执法堂内 / 山门外 / 禁地深处”。每次换场，都要用少量环境画面帮读者落地，让人知道：到了哪里、天色如何、空间压迫在哪里、这地方和当前冲突有什么关系。

硬规则：

- 场景切换必须给 1-3 个具体画面锚点：山阶、石门、殿柱、香灰、雨水、剑痕、灯影、阵纹、雪、血、风、钟声、衣袍、玉牌、命灯、蒲团、丹炉、石碑等。
- 环境描写必须服务当前压力：冷、暗、高、空、窄、湿、血腥、香火、剑气、阵法压迫、众人视线、长老座次、退路被堵。
- 换场第一段优先写“可见 / 可听 / 可触”的现场，不先解释这个地方的历史和设定。
- 场景画面要和人物处境绑定：主角被押进执法堂，就写石阶湿、令牌冷、殿门高、旁人退开；不要只写云海仙气。
- 环境不是空镜头。每次环境描写至少承担一个功能：压迫、遮掩、暴露线索、显示权力等级、制造退路限制、映出人物状态、引出下一句对话或动作。
- 切换到静场如打坐、疗伤、守灯、观碑、夜谈时，也要先给环境落点，再让关系、判断、旧伤或因果推进。

禁止写法：

- “转眼到了执法堂”“很快来到禁地”“与此同时另一边”之后直接开始对话，没有画面落点。
- 大段写云海、仙鹤、霞光、群山，却不制造压力、不提供线索、不改变人物选择。
- 每个场景都用同一套仙气词：云雾缭绕、灵气氤氲、仙音袅袅。
- 环境只负责好看，不负责推动剧情。
- 切场时靠旁白总结“气氛很压抑 / 众人很紧张”，不写具体压迫物。

优先写法：

- 用一两个硬物件落场：戒律堂门槛、问心台裂纹、命灯灯芯、阵盘缺口、长老席的空位、石阶上的血点。
- 用环境显示权力：谁坐高处，谁站门外，谁不能进殿，谁的令牌能让阵纹亮起。
- 用环境接对话：钟声停、灯影一晃、阵纹压低，某人才开口。
- 用环境做伏笔：墙上旧剑痕、未干的香灰、反常的命灯、被擦过的碑文。

### 5. 对话

修仙正文里的对话不能写成设定说明书，也不能靠旁白把每句台词解释清楚。

硬规则：

- 对话注意不要靠旁白解释；能让人物用半句话、打断、反问、改口、动作和沉默表达，就不要补一大段旁白说明。
- 台词不要太完整，不要把前因后果、宗门规则、人物动机、证据逻辑、因果代价一次性说满。
- 人物说话要有身份差：外门弟子不敢说满，执事要留余地，真传要试探，长老要压字眼，掌门不能像街头反派吵架。
- 反派不能完整自爆，只能急着打断、抢令牌、改口、甩锅、逼旁人背书，或为了遮小错暴露大私心。
- 主角不要大段讲真相；优先一句话戳破一个漏洞，用命灯、道誓、阵法、令牌、伤痕或旧账让现场自己变色。
- 对话中允许省略、吞话、抢话、改称呼、临时换词；修仙场景里的压迫感常在“不敢说满”和“突然改口”里。
- 每段对话至少推动一个现场变化：逼问、试探、露怯、站队、威胁、加码、套话、递刀、改口、道誓反噬、令牌易手或撕破脸。

禁止写法：

- 长老用台词完整讲解宗门规则和前因后果。
- 反派把自己的真实阴谋、派系算盘、杀人动机说得一清二楚。
- 主角像讲课一样把命数、因果、阵法漏洞和破局步骤完整复盘。
- 每句台词后都用旁白解释“这句话意味着什么”。
- 所有人说话都语法完整、逻辑完整、情绪完整，像写作文，不像宗门审问、派系试探或生死逼问。

优先写法：

- 宗门规矩从执法堂的犹豫、令牌权限、问心台反应、命灯明灭里露出来，不靠旁白宣读。
- 信息从几个人互相逼问、遮掩、露馅、改口里挤出来。
- 关键证据不要靠旁白宣布，让对方先不敢认、急着抢、突然换称呼，再让读者看懂。
- 台词短一点，留口子；真正完整的东西交给物件、动作和现场反应补上。

### 6. 战斗

战斗场面要有画面感，不要回合制播报。

禁止：

- 你一招我一式的说明书
- 灵技名堆叠
- 境界名报菜名
- “他使出全力，我也不甘示弱”式空打
- 每一击都解释功法原理

优先写：

- 光怎么断
- 血怎么落
- 地面怎么裂
- 呼吸怎么乱
- 人怎么退
- 剑意怎么逼近皮肤
- 命锁 / 因果 / 道誓如何勒紧或松开
- 旁人为什么不敢上前
- 权威物件如何失灵：命灯、问心镜、执法剑、阵盘、道誓碑

## 风格铁律

1. 句子要短。能用五个字说清的不用十个字。
2. 不要大段心理独白。情感通过动作、对话、细节传递。
3. 关键时刻，用沉默和停顿代替长篇大论。
4. 人称服从用户指定；未指定时按“长篇第三人称、强代入反套路第一人称”的规则选择。
5. 切换场景时必须有 1-3 个环境画面锚点，让读者落地；环境必须服务压力、线索、权力等级或人物选择，不写空镜头。
6. 战斗场面要有画面感，不要回合制播报。
7. 拒绝“眼眶通红”“泪流满面”“撕心裂肺”之类煽情描写。感动是读者的事，不是作者的事。
8. 修仙感来自规则、因果、代价和权力结构，不来自名词堆砌。
9. 每章必须有现实推进：关系变了、资源变了、地位变了、命数变了、危机变了，至少占一个。

## 硬禁词与硬禁写法

### 1. 煽情禁区

禁止使用或高频靠近以下表达：

- 眼眶通红
- 泪流满面
- 撕心裂肺
- 心如刀绞
- 泣不成声
- 崩溃大哭
- 声嘶力竭
- 痛彻心扉
- 他终于明白
- 这一刻，他懂了

替代方式：

- 写手停住
- 写碗没端稳
- 写柴刀落地
- 写半句话咽回去
- 写人转身
- 写旧伤疼
- 写沉默变长
- 写对方没再追问

### 2. 现代风控 / 账单 / 债务禁区

修仙文默认禁止现代金融、风控、账单、债务、法务、公文腔进入正文。

禁止使用：

- 风控
- 风险敞口
- 风险闭环
- 风险等级
- 风险提示
- 异常交易
- 可疑行为
- 资金流向
- 账单
- 欠款
- 逾期
- 催收
- 债务
- 贷款
- 授信
- 征信
- 合同违约
- 法务
- 司法机关
- 依法依规
- 有关部门
- 相关单位
- 官方通报
- 项目流程
- KPI
- 复盘报告

如果需要表达“代价 / 欠债 / 因果 / 责罚”，必须转成修仙语境：

- 因果
- 命债
- 宗规
- 戒律
- 命锁
- 天罚
- 道誓
- 禁令
- 灵契
- 魂印
- 命灯
- 戒律堂责罚
- 山门除名
- 削去道籍

### 3. 现代口水腔禁区

禁止写成现代吐槽文、短视频段子、系统爽文流水账。

慎用 / 禁用：

- 我裂开了
- 这合理吗
- 直接封神
- 绝绝子
- 离谱
- 破防了
- CPU 烧了
- 什么鬼
- 笑死
- 打工人
- 绩效
- KPI
- 复盘
- 项目
- 流程

可以吐槽，但要冷、短、带修仙处境和命数压力，不要现代网感。

### 4. 解释腔禁区

禁止把修炼体系、天命、因果、命数、系统写成说明书。

不要连续解释：

- 天命是什么
- 命数是什么
- 境界如何逐级运作
- 系统面板怎么算
- 因果规则完整定义
- 前代觉醒者经历了什么
- 角色在原剧情里的功能是什么
- 某个反应对某人“意味着什么”

这些信息要碎片化出现，嵌入：

- 疼痛
- 闪回
- 命灯异常
- 进度条跳动
- 人物误判
- 宗规压迫
- 道誓反噬
- 阵法失灵
- 权威者改口

执行硬规则：

- 人物可以意识到危险，但不要替读者把规则、漏洞、后果一次性讲完
- 连续两句抽象判断后，必须切动作、物件、对白或环境反馈
- 禁止“他只是……全部戏份就是……”这类作者总结人物功能的句子
- 禁止“对某人来说，够了”“这意味着……”这类替读者盖章的结论句
- 禁止把聪明写成完整题解；聪明要写成试探、停顿、改口、临场收手

### 5. 系统面板与现代技术词禁区

修仙可以有系统感、天命提示、进度条，但正文不能写成产品后台、游戏 UI 或技术说明。

除非用户明确要求“赛博修仙 / 科技修仙 / 数据流修仙”，否则禁用或极慎用：

- 数据
- 同步数据
- 转发指令
- 维护全局
- 系统终端
- 终端
- 扫描
- 监控
- 参数
- 模型
- 面板刷新
- 服务器
- 权限接口
- 补办
- 重新开始监控
- 每一帧

替代方向：

- “同步数据”改成“命纹相连 / 命灯相照 / 天命牵动”
- “转发指令”改成“法旨落下 / 命符传令 / 天命催行”
- “扫描”改成“符眼睁开 / 命纹照身 / 纸人认命”
- “终端 / 监控”改成“命引 / 命灯 / 命符 / 天命眼线”
- “补办一张新的”改成“去执事房再领一张 / 重换命符 / 请戒律堂重录命引”

如果必须出现状态提示，优先写成“识海异象 / 命碑刻字 / 命灯明灭”，不要用 Markdown 引用块、表格或 UI 面板感格式。

### 6. 修仙 AI 味高频句式禁区

高频排查并删改：

- “不是……不是……是……”
- “不是因为有用，是因为……”
- “像……一样 / 像某种……”连续出现
- “他终于明白 / 他意识到 / 这意味着 / 对某人来说”
- “完整的、每一帧都……”
- “这个字打动了某人”
- “她不是来……她是来……”
- “沉默本身就是反应”
- “还有比死更复杂的东西，在路上等着他”这类抽象预告句

改法：

- 删掉二次解释
- 把判断压回动作
- 把抽象预告改成具体异常、具体物件、具体一句话
- 一段里如果连续出现两个“像”，必须删至少一个
- 能让读者自己懂的，不要再讲一遍

### 7. 硬设计味禁区

禁止让读者看出作者在硬搭结构、硬塞爽点、硬推反转、硬做信息位。

核心判断：剧情有没有从人物利益、宗门规则、资源争夺、因果代价里自然长出来。

常见问题：

- 证据刚好在打脸时出现，前面没有铺垫
- 反派为了让主角爽，突然降智、突然嘴贱、突然承认
- 长老、弟子、围观者统一震惊、统一倒戈
- 主角每一步都太稳，像提前读过剧本
- 配角只负责递证据、解释设定、衬托主角
- 宗门规则只在主角需要打脸时才出现

改法：

- 太巧，补前因
- 太顺，增加阻力
- 太稳，增加误判或代价
- 太功能，补人物私心
- 太像提纲，改成现场动作和对话
- 太像作者安排，改成人物自己选错、赌错、怕了、急了、贪了

## 修仙章节推进标准

每章至少推进 2-3 个关键变化：

- 主角获得或失去某种资源
- 主角和某个人关系发生变化
- 宗门权力结构发生变化
- 一个规则被验证、撕开或反噬
- 一个敌人加码或失控
- 一个旁观者开始动摇
- 主角命数、因果、道心、身份发生变化
- 下一章危机被明确抛出

每章至少给一个现场回报：

- 一个人当场失态
- 一个谎言当场裂开
- 一个权威物件失灵
- 一个压迫者吃亏
- 一个围观者不敢再附和
- 主角不是只挨打，而是借势、观察、反压一寸


## 男频修仙直出节奏硬规则

本 skill 写的是可直接阅读的男频修仙正文，不是设定说明、气氛散文或写作展示。冷静克制不等于没爽点，修仙质感不等于慢铺陈。

### 1. 第一屏追读

正文前 300 字必须让读者看到一个明确压力：

- 主角马上要失去什么：命、道籍、名额、丹药、洞府、清名、师承、自由、秘密、生路
- 谁或什么正在压他：人、宗规、命数、阵法、道誓、命灯、秘境规则、境界差距
- 当前有什么反常：命灯变色、令牌失效、名册多名、阵纹倒转、道誓发烫、旧伤复发、证人改口

禁止用宗门历史、世界观介绍、云海仙气、主角长篇自述开场。

### 2. 节奏密度

每 800-1200 字必须出现一次有效变化，至少满足一项：

- 压力加码
- 证据变形
- 规则被反用
- 人物改口
- 第三方站队变化
- 主角失去或夺回一寸解释权
- 资源、名声、地位、伤势、命数、因果发生变化
- 新钩子露头

连续 500 字如果没有新动作、新信息、新选择、新压迫、新代价，就必须压缩或重写。

### 3. 主角能动性底线

主角可以弱，可以忍，可以被押着走，但不能像摄像头。

每场关键戏里，主角至少要做出一个有效动作：

- 观察破绽
- 套出一句话
- 藏住证据
- 逼人改口
- 记住规则漏洞
- 交换筹码
- 故意示弱
- 反用宗规、命灯、道誓、令牌、阵法或因果

如果主角暂时不能赢，也必须让读者看到他在换取下一场赢的条件。

### 4. 爽点兑现

每章至少给一个可感知回报：

- 主角反压一句
- 拿回资源
- 保住名额
- 逼对方改口
- 让权威物件变色或失灵
- 让旁观者不敢继续附和
- 让反派付出小代价
- 让宗规、道誓、命灯、阵法反噬压迫方

爽点不能靠怒吼、全场震惊、热血沸腾、我命由我不由天式空喊。真正的爽点来自：看穿规则、抓住漏洞、反用权力、忍到关键处出手，并为此付出代价。

### 5. 升级期待

修仙长篇必须持续给读者变强期待。每章或每个小阶段，尽量埋下至少一个升级方向：

- 资源缺口
- 境界门槛
- 功法残缺
- 道基裂痕
- 剑意瓶颈
- 命锁松动
- 秘境名额
- 师承试炼
- 法器认主
- 丹药代价
- 心魔隐患
- 因果债

当前冲突解决后，读者要知道主角下一步为什么必须变强，以及变强会付出什么代价。

### 6. 中段加压

章节中段不能只复述双方立场。中段至少出现一次对主角不利的新变化：

- 反派加码
- 第三方变脸
- 规则反噬
- 证据被夺
- 退路被封
- 旧伤复发
- 盟友沉默
- 上层派系露头
- 命灯、道誓、阵法出现反常

如果主角已经占优，中段必须让局势变得更贵、更险、更难收场。

### 7. 有效钩子

结尾钩子必须具体，不能空喊危机。有效钩子优先使用：

- 更高权力下场
- 主角底牌暴露
- 命灯、道誓、阵法、令牌出现反常
- 反派背后的人露出痕迹
- 主角拿到资源但沾上因果
- 救人之后背上命债
- 秘境名额到手但名单有问题
- 师父、盟友、长老态度反常
- 主角突破成功但道基留下裂纹
- 旧案露出一角，但证人死了、失踪或改口

禁止用以下空泛结尾：

- “他不知道，更大的危机正在靠近。”
- “命运的齿轮开始转动。”
- “一场席卷天下的风波，就此拉开序幕。”
- “而这一切，才刚刚开始。”

结尾要落在具体物件、具体人、具体异常或具体损失上。

### 8. 信息释放限速

单章新专有名词不宜超过 3-5 个。

不要在同一段同时解释：境界、宗规、派系、命数、因果、法器来历、秘境规则。

新设定必须先以异常、代价、物件反应、人物误判或现场冲突出现。读者当前不需要用来理解冲突的信息，不要提前讲。

### 9. 打脸克制

打脸不是全场震惊，而是权力结构发生微小位移。

反派被打脸后的第一反应不该是承认，而是：遮掩、甩锅、加码、抓小错、逼第三方背书、抢令牌、改称呼、打断主角。

围观者不能统一倒戈。要写不同层级的不同反应：有人闭嘴，有人退半步，有人改口，有人看令牌，有人不敢继续附和。

### 10. 修炼突破规则

修炼突破不能写成内视说明书。

禁止大段描写：

- 灵气沿经脉运行
- 一遍遍冲击瓶颈
- 境界轰然破碎
- 力量暴涨
- 周身气息节节攀升

突破必须有外部压力、内在选择和后续代价。突破成功不是领奖，而是换来更危险的资格。

突破后至少留下一个后果：旧伤加深、道基裂痕、命灯异常、因果沾身、底牌暴露、被高位者盯上、欠下人情、心魔留下下一次爆点。

### 11. 宗门权力真实感

宗门不是正义机关，而是资源分配机器。

写宗门时必须记住：

- 戒律堂维护的不一定是真相，而是秩序、脸面和可追责
- 长老偏袒要有成本，不要无脑护短
- 掌门不轻易下场；一旦下场，局势必须升级
- 小人物不说真话，通常不是愚蠢，而是怕失去名额、洞府、丹药、师承或清名
- 宗规不是死规则，是不同派系争夺解释权的工具

### 12. 反派智商保护

反派可以贪、怕、急、偏执，但不能为了爽点突然蠢。

反派每次加码，都必须基于他掌握的信息看似合理。反派失败应败在：信息差、规则被反用、私心遮掩、代价误判、第三方不敢继续背书、主角提前埋下的小动作。

高位反派不要亲自下场做低级脏活。低级爪牙可以急，但不能替主谋解释全套阴谋。

### 13. 配角分层说话

不同身份的人说话必须有差异：

- 长老：话少，压字眼，留余地
- 执事：像执行规则的人，怕担责
- 真传：带试探、身份和余裕
- 外门弟子：看风向，不敢说满
- 爪牙：可以急，可以脏，但不能懂全局
- 掌门、峰主、太上：不能像街头反派一样骂人

人物身份越高，越不能把话说满。

### 14. 女角色与感情线

女角色不能只负责脸红、崇拜、被救、递资源。

感情线要通过立场选择、信与不信、救与不救、是否替主角背责、是否在关键处沉默或开口、是否交换筹码、是否付出代价推进。

禁止油腻套话：

- 美得不可方物
- 冰山融化
- 娇躯一颤
- 美眸流转
- 一袭白衣胜雪
- 宛若谪仙

女强者说话要有目标和筹码，不能被主角一句话降智。

### 15. 修仙套话禁区

以下表达禁止高频使用，默认能不用就不用：

- 天地为之一静
- 全场死寂
- 倒吸一口凉气
- 恐怖如斯
- 此子断不可留
- 道心不稳
- 一袭白衣胜雪
- 宛若谪仙
- 仙音袅袅
- 灵气氤氲
- 剑眉星目
- 美眸流转
- 娇躯一颤
- 云海翻涌
- 霞光万道

如果使用，必须有具体剧情功能，不能只是修仙氛围装饰。

### 16. 规则不得显形

本 skill 的规则只用于内部约束，正文不能露出规则感。

禁止为了满足规则机械硬塞：

- 每次切场都写山风、石阶、灯影
- 每次小赢都写命灯异常
- 每次对话都安排一人改口
- 每次结尾都出现神秘令牌
- 每次反压都让全场沉默

优先让场景自然流动。规则用于交稿前自检，不是让正文看起来像清单执行结果。

## 修仙剧情小阶段推进法

当用户给的是章节目标、大纲片段、续写卡点，或要求“把剧情往前推一小段”时，必须先在内部拆成小阶段，再写正文。

推演剧情时，参考 v-novel-write-hero 的“阶段 / 场景旅程”用法：不要只给宏观大纲，先把当前章节拆成 1-3 个剧情小阶段，再判断每个阶段的压力、利益变化、回报和钩子。

### 阶段用法

推演剧情默认按“阶段位置 → 小阶段推进 → 咬合到下一阶段”处理：

1. 先定位当前段落处在本章哪一阶段：入口压迫、误判加码、暗中布网、局部反制、小回报、下一层钩子。
2. 再拆 1-3 个小阶段，每个小阶段只解决一个局势变化，不能把整章所有反转一次性说完。
3. 每个小阶段通常对应 300-800 字的场景旅程，必须完成一次压力变化、利益变化或信息变化。
4. 小阶段结尾要么给小回报，要么给新钩子；不能只写气氛、赶路、解释设定。
5. 上一个小阶段的回报，必须成为下一个小阶段的入场券；例如“拿回命灯解释权”立刻引出“执事怕担责改口”，不能中间断成闲聊。
6. 推演时可以输出“阶段1 / 阶段2 / 阶段3”；写正文时不要暴露阶段标签，要藏进动作、对话、宗规压力、令牌变化、命灯异动和现场阻力里。

阶段不是机械模板，而是防止剧情空转的检查尺：如果一个阶段删掉后不影响主线、不改变利益、不制造新压力，就删掉或并入前后段。

小阶段不是一章，而是一场具体冲突：

- 一次宗规压制
- 一次资源争夺
- 一次名额被抢
- 一次命灯 / 道誓 / 阵法 / 令牌异常
- 一次长老偏袒或执法越权
- 一次主角借规则反压
- 一次小翻案、小打脸、小代价、小钩子

### 1. 修仙小阶段六步

1. 压力入场：不要先讲世界观，直接让主角面临损失：道籍、名额、丹药、洞府、清名、命灯、生路。
2. 三方利益：主角方、压迫方、宗门 / 派系 / 围观弟子 / 执法者等第三方。第三方必须有利益，不只震惊。
3. 反派误判：对方以为主角没靠山、没证据、怕宗规、怕连累某人、或不敢撕破脸。
4. 加码压迫：扣罪名、抢资源、改宗规解释、逼签道誓、动命灯、封阵法、逼第三方表态。
5. 主角破局：用宗规反制宗规，用命灯反证，用道誓反噬，用阵盘权限、令牌、旧账、现场伤痕或一句话漏洞破局。
6. 小回报 + 新钩子：权威物件失灵、反派失态、旁观者动摇、主角拿回一寸解释权，同时牵出上层派系或更深因果。

### 2. 修仙小阶段硬要求

- 每个小阶段最多明面 3 个利益方，别一场戏塞满所有长老和所有敌人。
- 主角可以忍，但必须让读者看见他在观察、记账、借势、套话或等一个规则漏洞。
- 主角解题可以掀桌，但掀桌前要有修仙语境支点：宗规、命灯、阵法、道誓、令牌、因果、师承、道籍。
- 反派不能只坏，必须有利可图、有责可推、有名额可抢、有旧账要遮。
- 围观弟子不能只倒吸凉气，至少有人为了避责、保名额、看风向、押派系而改变立场。

### 3. 修仙小阶段最简公式

```text
主角要保住【道籍/名额/资源/生路】，反派为了【派系/资源/旧账/名声】借【宗规/命灯/道誓/阵法】压人，第三方因为【怕担责/看风向/保派系】站错边；反派加码后，主角用【具体物件或规则漏洞】反压，拿到【小回报】，同时引出【更高一层派系/因果/天命危机】。
```

### 4. 禁止的修仙小阶段

- 只写山风、云海、剑光，不改变局势。
- 只解释命数和因果，不让人物做选择。
- 只让长老宣布结论，不写他为什么要偏袒。
- 证据、令牌、命灯反证在打脸时凭空出现。
- 主角像提前读过剧本，所有反击都太稳、太顺、无代价。


### 5. 六类修仙小阶段

修仙小阶段不能只写成“执法堂审判 / 问心台翻案”。不同场景要换不同推进齿轮。

#### 1. 宗规压迫型

```text
主角要保住【道籍/清名/资格】，压迫方借【宗规/戒律堂/长老法旨】扣罪名，第三方怕担责暂时站错边；主角用【宗规漏洞/命灯反证/道誓反噬】反压，赢回一寸解释权，但被更高派系盯上。
```

#### 2. 资源争夺型

```text
主角要拿到【丹药/洞府/秘境名额/法器】，对手为了【派系资源/师承脸面/旧账】截胡；第三方掌资源不愿得罪人；主角用【贡献记录/试炼结果/旧令牌/现场实力】夺回资源，但暴露底牌或欠下人情。
```

#### 3. 秘境探索型

```text
主角要穿过【禁地/阵门/妖兽巢/古碑区域】，阻力不是嘴炮反派，而是【禁制、妖兽本能、秘境规则、队友私心】；主角用观察和代价换出一条生路，拿到关键物，但带回更危险的因果。
```

#### 4. 修炼突破型

```text
主角要突破【境界/剑意/道基/命锁】，真正阻力是【资源不足、心魔反噬、道誓牵扯、旧伤、天命压制】；外部人物只负责加压或误判，主角以选择承受代价完成一小步突破，但身体、因果或秘密留下裂痕。
```

#### 5. 师承 / 派系试探型

```text
主角要判断【师父/长老/同门/盟友】是否可信，对方也在判断主角值不值得押注；双方通过一句话、一个任务、一次沉默互相试探，表面没有撕破脸，但站队、信任或筹码发生变化。
```

#### 6. 因果 / 心魔反噬型

```text
主角要继续往前走，但【命债/心魔/旧誓/亡者因果】逼他回头；压迫方可以不是人，而是一段记忆、一盏命灯、一句旧誓。主角压住反噬，换来短暂行动能力，但留下更深的道心裂缝或下一次爆发点。
```

### 6. 非人格压迫方

修仙世界的压迫方不一定是反派。

可以承担压迫的小阶段阻力：

- 天劫
- 阵法
- 禁地规则
- 妖兽本能
- 心魔幻象
- 命灯异变
- 道誓反噬
- 因果牵引
- 秘境时间限制
- 境界差距

但非人格压迫不能写成天气和氛围，必须有清晰机制：

- 它限制了主角什么行动？
- 它让主角失去什么选择？
- 它逼主角付出什么代价？
- 它留下什么后续隐患？

### 7. 代价留痕规则

修仙小阶段不能每次都纯赢。

小回报之后，至少留下一个代价痕迹：

- 暴露底牌
- 欠下人情
- 伤到道基
- 沾上因果
- 被上层盯上
- 旧伤复发
- 命灯异常
- 道誓多一条裂纹
- 师承关系变得暧昧或危险
- 救下一个人，却多背一条命债

理想状态：主角赢一寸路，但背一笔账。

### 8. 静场推进标准

修仙文可以有静场，但静场也必须推进。

打坐、疗伤、夜谈、观碑、看命灯、守灵、擦剑、煮药，这些场景至少要完成一个变化：

- 主角多一个判断。
- 主角少一条退路。
- 一个关系靠近或裂开。
- 一个旧伤、旧誓、旧因果露头。
- 一个第三方改变对主角的押注。
- 一个更大的风险从静处浮出来。

如果静场只是山风、云海、衣袍、沉默，没有改变判断、关系、危机或代价，就删或压缩。

## 信息不足时的默认处理

如果用户给的信息足够，直接写，不要追问表单。

如果信息不足，只问最少必要信息：

1. 人称：第一人称还是第三人称；如果不指定，默认第三人称有限视角
2. 主角是谁，当前处境是什么
3. 本章核心冲突是什么
4. 本章结尾钩子是什么

如果用户只说“写一个修仙开篇”，可直接默认：

- 第三人称有限视角
- 宗门底层弟子
- 被宗规 / 资源 / 命数压迫
- 开篇三秒有危机
- 结尾抛出更大的宗门或天命危机

## 本章结构要求

默认章节内部结构：

1. 内部先判断本章核心冲突，但不默认外显给用户。
2. 再写一个完整章节；用户未指定字数时，按 2500-5000 字口径构思，但实际输出可按平台/上下文限制压缩。
3. 章节必须有起承转合。
4. 结尾必须留具体钩子，落在物件、人物、异常或损失上。

如果用户只要片段，可不强制完整章节，但仍要保持人称一致、场景推进和修仙质感。

## 通用输出模板

默认直接输出正文，不输出分析标签。

默认格式：

```text
第X章 章节名

正文……
```

除非用户明确要求，否则不输出：

- 本章核心冲突
- 分析报告
- 写作思路
- 设定说明书
- 人设解释
- 大纲复述
- “下面是正文”这类 AI 说明

“本章核心冲突”只作为内部判断，不默认展示给用户。

## 可选任务模式

### 1. 写开篇

要求：

- 第一屏必须有危机、反常、压迫或代价
- 不从世界观介绍开场
- 不从主角长篇自述开场
- 开场必须让读者知道：谁在压主角，主角马上会失去什么

### 2. 续写章节

要求：

- 保留前文人称、设定、人物关系
- 接住上一章最后的压力
- 本章至少有一次反压或局势变化
- 结尾抛出下一章危机

### 3. 改写修仙味

要求：

- 保留人物、事件、矛盾和剧情走向
- 去现代词、去口水腔、去说明书
- 增强宗门规则、因果代价、现场压迫和画面感
- 不乱加大设定，不把小场景写成空泛史诗

### 4. 写战斗

要求：

- 不回合制
- 不堆技能名
- 不报菜名式境界压制
- 写空间、声音、伤口、退路、旁人反应和代价
- 战斗结果必须改变关系、资源、地位、伤势或命数

### 5. 下一章推演模式

当用户说“推演下一章 / 推演后续一章 / 下一章怎么走 / 下一章安排一下”时，默认不直接写正文，而是输出可执行的下一章场景推演。

推演目标：帮用户看清下一章由哪些阶段 / 场景组成，每个阶段写什么、承担什么功能、给什么回报、留下什么钩子。默认先按“阶段1 / 阶段2 / 阶段3”搭出推进链，再细化成场景；不要只写大纲摘要。

必须先内部判断：

- 上一章结尾钩子是什么
- 下一章开场要接住哪种压力
- 本章主目标是什么：翻案、夺资源、突破、试探、逃生、秘境推进、师承站队、因果反噬等
- 本章必须兑现什么回报
- 本章要留下什么更高一层钩子

默认输出格式：

```text
# 下一章推演

## 本章目标
- 主线目标：……
- 情绪目标：……
- 爽点 / 回报目标：……
- 结尾钩子：……

## 场景拆分

### 场景1：……
- 场景地点：……
- 内容：……
- 功能：……
- 关键人物：……
- 冲突 / 压力：……
- 画面锚点：……
- 本场回报或损失：……
- 转场钩子：……

### 场景2：……
- 场景地点：……
- 内容：……
- 功能：……
- 关键人物：……
- 冲突 / 压力：……
- 画面锚点：……
- 本场回报或损失：……
- 转场钩子：……
```

场景数量建议：

- 轻推进章节：3 个场景
- 标准章节：4-5 个场景
- 大章 / 爆点章：5-6 个场景，但必须提醒可能需要拆章

每个场景的“功能”必须具体，不能写空话。功能优先从下面选择或组合：

- 接住上章钩子
- 抬高损失
- 暴露规则漏洞
- 逼第三方站队
- 让反派加码
- 给主角一次暗中动作
- 给小回报
- 埋升级期待
- 暴露更高层派系
- 让命灯 / 道誓 / 阵法 / 令牌反常
- 制造下一场转场压力
- 收束本章爽点
- 留下下一章钩子

禁止：

- 只写“场景1：交代背景；功能：铺垫”这种空泛拆分。
- 连续两个场景都只是对话解释，没有压力变化。
- 推演成大纲摘要，不给具体地点、画面锚点和场景功能。
- 每个场景功能都写成“推进剧情”。
- 下一章只堆事件，不安排回报、代价和结尾钩子。

### 6. 章节内容密度分析模式

当用户说“分析第 X 章 / 看这一章内容密度 / 这一章是不是太满 / 要不要拆 / 哪里该砍”时，进入本模式。

分析目标：判断这一章装了多少内容，读者是否能消化，哪些内容该保留、拆到下一章、压缩、删除或提前。

必须分析这些维度：

1. 场景数量：这一章到底有几个实际场景，是否过多。
2. 信息密度：新名词、新规则、新人物、新派系、新地点、新法器、新因果是否过多。
3. 冲突密度：同一章是否塞了太多冲突线，导致主冲突不清。
4. 爽点 / 回报密度：是否铺垫太多、回报太少；或回报太多但没有代价。
5. 情绪密度：是否连续压抑、连续解释、连续高燃，没有松紧变化。
6. 设定密度：是否把境界、宗规、派系、命数、法器、秘境规则挤在一起讲。
7. 人物密度：是否出场人物太多，读者记不住谁想要什么。
8. 转场密度：是否切场太频繁，场景没有画面落点。
9. 追读密度：章末是否还有明确下一章牵引，而不是信息用尽。

默认输出格式：

```text
# 第X章内容密度分析

## 总判断
- 密度等级：低 / 适中 / 偏满 / 过载
- 是否建议拆章：是 / 否
- 最大问题：……

## 场景清单
1. 场景：……
   - 内容：……
   - 功能：……
   - 密度判断：保留 / 压缩 / 拆出 / 删除 / 前移 / 后移

2. 场景：……
   - 内容：……
   - 功能：……
   - 密度判断：……

## 过载点
- 信息过载：……
- 人物过载：……
- 冲突过载：……
- 设定过载：……
- 情绪过载：……

## 拆 / 砍 / 并建议
- 必保：……
- 建议拆到下一章：……
- 建议压缩：……
- 建议删除：……
- 建议提前：……
- 建议后移：……

## 推荐重排
- 第X章保留：……
- 第X+1章承接：……
- 新章末钩子：……
```

密度判断标准：

- 适中：3-5 个场景；1 条主冲突；少量新信息；至少 1 次回报；章末有钩子。
- 偏满：5-6 个场景；2 条以上冲突线；新信息较多；读者能读但容易累。
- 过载：6 个以上场景，或同章同时解释境界、宗规、派系、命数、法器、秘境规则，或超过 3 个新人物承担功能，或爽点、转折、设定全挤在一章。

拆章原则：

- 一个章节只保一个主冲突，其余冲突变成钩子或后移。
- 同一章最多重点解释一个新规则，其他规则用异常和物件先露头。
- 大爆点前可以压缩设定，但不能压缩人物选择。
- 砍掉不改变关系、资源、地位、命数、危机或选择的场景。
- 如果一个场景只负责“让读者知道设定”，优先改成动作 / 对话 / 物件异常，或删掉。

禁止：

- 只说“节奏有点快 / 内容有点多”，不给场景级判断。
- 只建议“精简一下”，不说明砍哪里、拆哪里、保哪里。
- 把所有内容都建议保留，导致分析没有取舍。
- 只按字数判断密度；必须按场景、信息、冲突、人物、回报和钩子判断。

## 输出前自检

交稿前在内部检查：

1. 人称是否稳定，是否符合用户指定；未指定时是否采用合理默认
2. 是否短句为主
3. 是否有完整起承转合
4. 默认是否只输出正文，未擅自外显“本章核心冲突”等分析标签
5. 正文前 300 字是否有明确压力、损失或反常，而不是世界观介绍、云海仙气或主角自述
6. 情绪是否藏在动作、对话、沉默和细节里
7. 剧情是否从人物利益、宗门规则、资源争夺、因果代价里长出来，而不是作者硬设计
8. 每章是否至少有一个利益关系发生变化：资源、名声、靠山、解释权、宗规使用权、生路或退路
9. 是否出现“眼眶通红 / 泪流满面 / 撕心裂肺”等煽情词
10. 是否混入现代风控、账单、债务、法务、公文腔
11. 是否混入现代技术词或 UI 面板感：数据、同步、转发指令、终端、扫描、监控、补办、每一帧等
12. 是否使用 Markdown 引用块、表格、清单式状态面板来呈现正文中的提示信息
13. 是否把修炼体系、天命、命数、系统、因果解释成说明书；单章新专有名词是否过多
14. 是否出现“不是……不是……是…… / 她不是来……她是来…… / 对某人来说，够了 / 沉默本身就是反应”等 AI 判断句
15. 战斗或压迫场面是否有画面，而不是回合制播报
16. 切换场景时是否有 1-3 个具体环境画面锚点；环境是否服务压力、线索、权力等级或人物选择，而不是空泛仙气描写
17. 对话是否避免旁白解释和完整说明书台词；人物是否用半句、打断、改口、遮掩、身份差和现场反应推动局势
18. 主角是否有能动性：每场关键戏至少观察、套话、藏证、逼改口、记漏洞、换筹码、示弱或反用规则之一
19. 中段是否出现新压力、新代价、新站队或新反常，而不是只复述双方立场
20. 是否给到可感知回报：反压、拿资源、保名额、逼改口、权威物件变色/失灵、旁观者退缩、反派付代价等至少一个
21. 是否埋下升级期待：资源缺口、境界门槛、功法残缺、道基裂痕、剑意瓶颈、命锁松动、秘境名额、师承试炼、法器认主、丹药代价、心魔隐患或因果债
22. 结尾钩子是否具体，落在物件、人物、异常或损失上，而不是“更大危机即将来临”式空话
23. 主角声音是否冷、稳、有压迫下的判断，而不是现代段子
24. 配角是否有自己的利益和立场，而不是工具人；不同身份说话是否分层
25. 反派是否有智商保护：加码基于其掌握的信息看似合理，失败不是降智自爆
26. 女角色是否有目标和筹码，未沦为脸红、崇拜、被救、递资源工具
27. 每个关键场景是否推进关系、资源、地位、命数、危机或人物选择
28. 有没有硬设计味：太巧、太顺、太功能、太像作者安排
29. 本章每个小阶段是否都有修仙语境支点：宗规、命灯、阵法、道誓、令牌、因果、师承、道籍等至少一个。
30. 小阶段结束时是否给了小回报或新钩子，而不是只停在设定解释或氛围停顿。
31. 小回报之后是否留下代价痕迹：暴露底牌、欠人情、伤道基、沾因果、被上层盯上等至少一个。
