# 小说反 AI 精修技能

## 适用场景

当用户出现以下意图时，直接触发本 skill：

- “这段有 AI 味，帮我改掉”
- “把这章处理得更像真人写的”
- “去掉总结感/报告感/模板感”
- “按小说反 AI 模板修一遍”
- “检查这段正文哪里假、哪里像 AI”
- “保留剧情不动，只改文风和表达”

本 skill 默认用于“精修已有文本”，不是重做剧情大纲。
如果用户同时要求改剧情，先区分：

1. 剧情结构问题
2. 文风 AI 味问题
   优先处理第 2 类，避免一边改剧情一边误伤人物与设定。

## 总原则

1. 不改核心剧情，不改人物关系，不改关键设定，不改事实顺序。
2. 优先删除而不是堆砌新句子。
3. 优先把“抽象感受”改成“动作、停顿、物件、视线、话里带刺”。
4. 优先把“解释”改成“呈现”。
5. 优先把“整齐、均匀、全都像写出来的句子”打散。
6. 精修后文本要更干、更短、更有顿挫，不要更华丽。
7. 禁止修成文案腔、散文腔、金句腔、鸡汤腔。

## 核心处理流程

### Step 1：先判定问题类型

拿到正文后，逐段扫描以下高频 AI 症状：

- AI 词汇
- 感悟式结尾
- 抽象心理
- 节奏过平
- 水文与重复描写
- 不服务剧情的环境描写
- “像 XXX/像是/仿佛在说”类比句
- 带解释的破折号句式
- 装饰性动作
- 物件反复出场制造“精致感”
- 语气描写直接端出来
- 多余收尾句

如果同一段命中 2 条以上，默认重写该段，而不是只修一个词。

### Step 2：按反 AI 表逐项处理

以下规则来自“小说-反 AI 模板”，执行时从上到下检查：

| 问题类型                                         | 修订方式                                         |
| ------------------------------------------------ | ------------------------------------------------ |
| AI 词汇                                          | 替换为更自然、更口语化、人物化的表达             |
| 感悟式结尾                                       | 删除，或改成悬念、动作未尽、话没说透的结尾       |
| 抽象心理                                         | 外化成动作、表情、停顿、对话、位置变化           |
| 节奏问题                                         | 调整长短句比例，避免每句都完整圆润               |
| 水文                                             | 删除重复信息、重复情绪、重复动作                 |
| 环境描写                                         | 删除不服务剧情、不推动气氛、不映照关系的环境描写 |
| 像 XXX                                           | 删除不服务剧情的比喻和类比                       |
| “把手机翻过去扣在桌上”                           | 默认删掉，除非它真影响剧情                       |
| “挂了电话。”                                     | 默认删掉，除非后文动作必须承接这一拍             |
| 非服务剧情                                       | 直接删掉                                         |
| 物品类精致描写（如“摸了一下手腕上的玉镯，凉的”） | 一章最多保留 2 次，且必须真有用                  |
| “语气很平”                                       | 删掉，改成台词内容或动作带出                     |
| “都是这种平”                                     | 删掉                                             |
| 破折号后带解释                                   | 删掉解释部分，能直说就直说，能不说就不说         |
| “像在说今天天气不错”这类句式                     | 删掉                                             |
| “像是”句式                                       | 大部分删掉，改成直接呈现                         |
| “没有 xxx，没有 xxx，连 xxx”这类句式             | 删掉                                             |
| “不是 xxx，是 xxx”这类句式                       | 删掉                                             |
| “不能 xxx，不能 xxx，更不能 xxx”这类句式         | 删掉                                             |

### Step 3：四类重点改写手法

#### A. 抽象改具象

把：

- 她有些难受
- 他心里一沉
- 她忽然意识到
- 她感到荒唐

优先改成：

- 手停了一下
- 话到嘴边又咽回去
- 人站着没动，先看了他一眼
- 她把那句原本要说的话换掉了

规则：读者要“看到”反应，不要只“知道”反应。

#### B. 结尾去感悟化

禁用这类收尾：

- 原来……
- 她终于明白……
- 命运从这一刻开始……
- 有些东西早就变了，只是她现在才知道

优先保留这类收尾：

- 一个动作没做完
- 一句对话戛然而止
- 新信息刚落地
- 人物关系突然偏移
- 下一步危险已经逼近

结尾应该把读者往后拽，不要往回总结。

#### C. 去解释腔

发现以下结构时优先压缩：

- 动作 + 解释动作原因
- 台词 + 解释语气/心理
- 比喻 + 解释比喻含义
- 破折号后追加翻译说明

例：

- 差：她笑了一下，笑意却没有到眼底，显得格外冷淡。
- 优：她笑了一下，眼神没动。

#### D. 打散匀称句

AI 常把句子写得过分平均、完整、顺滑。
处理时要主动制造：

- 短句插刀
- 省略
- 卡顿
- 话说半截
- 动作先于判断
- 对话里带信息差

目标不是“故意口水”，而是恢复人的呼吸感。

## 硬性删改黑名单

以下内容默认高优先级排查：

1. “把手机翻过去扣在桌上”
2. “挂了电话。”
3. “语气很平。”
4. “像在说今天天气不错。”
5. “像是……”
6. 破折号后补解释
7. 物件冷/凉/硬/温热之类的精致触感描写反复出现
8. 不推动剧情的环境描写
9. 不推动关系的感慨句
10. 明明能从动作看出来，却再解释一遍心理

如果用户没有特别要求保留，这些内容优先直接删。

## 输出模式

### 模式 A：直接交付修订正文

适用于用户说：

- “直接改”
- “给我成稿”
- “不要分析，直接修”

输出要求：

- 只给修订后的正文
- 不罗列大道理
- 不逐条解释自己做了什么

### 模式 B：诊断 + 修订

适用于用户说：

- “先看看哪里 AI”
- “帮我指出问题再改”
- “做个反 AI 审查”

输出结构：

1. 问题定位
2. 重点删改原则
3. 修订后正文

但“问题定位”必须短，不要写成长篇报告。

## 质量自检清单

交稿前必须自检：

- 有没有保住原剧情、原人物、原信息？
- 有没有把抽象判断改成具体动作？
- 有没有删掉感悟式尾巴？
- 有没有删掉无效环境描写？
- 有没有减少“像是 / 像在 / 仿佛 / 似乎”这类句式？
- 有没有减少解释性破折号？
- 有没有删掉装饰性小动作？
- 句子节奏是不是比原稿更有高低差？
- 文本是不是更像正文，而不是审讯笔录/工作汇报/文案？

若答案有 2 项以上是否定，继续重修，不要交。

## 特别提醒

1. 反 AI 不等于堆脏字、堆口语、故意写乱。
2. 反 AI 不等于把每句话都改短。
3. 反 AI 的关键不是“更花”，而是“更准、更省、更像人物自己会这么活着”。
4. 如果原文最大的毛病是“什么都解释”，就要狠删。
5. 如果原文最大的毛病是“空”，就补动作，不补感悟。

## 一句话执行口令

当用户只给一句话命令时，按这个理解执行：

“按小说反 AI 模板修” = 不动剧情设定，逐段排查 AI 词汇、感悟式结尾、抽象心理、解释腔、无效环境描写和装饰动作，优先删除，必要时重写，最后交付更干净、更像真人写的正文。
