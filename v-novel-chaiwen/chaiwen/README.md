# chaiwen

这个目录是 v-novel-chaiwen 的默认落盘目录（用于“直接粘贴到对话里的文字”）。

关键约定：
- `chaiwen/` 是目录，不是单个进度文件。
- 首次初始化时，这里可能只有本 README（或 `.gitkeep`）。这表示“目录已建立，但还没有实际拆文产物”。
- 真正用于续拆恢复的状态，应该写在：
  - `继续索引.md` 或 `<来源名>-继续索引.md`
  - `<来源名>-章节行号索引.md`
  - `拆文-第X章-第Y章.md` / `<来源名>-拆文-第X章-第Y章.md`
  - `阶段总结-第X章-第Y章.md` / `<来源名>-阶段总结-第X章-第Y章.md`

默认来源规则：
- 如果用户提供的是文本文件，拆文结果优先放到该文件同目录下的 `chaiwen/`
- 如果用户直接在对话里提供文字，拆文结果默认放到这里

续拆恢复最低要求：
- 继续索引里必须明确写出“最近已完整拆到第几章”“下一次必须从第几章开始”
- 章节行号索引必须单独落盘，不能只留在对话记忆里
