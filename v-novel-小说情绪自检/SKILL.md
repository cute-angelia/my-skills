核心法则：

```text
读者情绪 ≠ 角色情绪。
不要只写角色很痛苦、很愤怒、很委屈；要让读者知道他为什么在乎、正在失去什么、为什么非行动不可。
```

## 何时触发

用户出现以下意图时使用本 skill：

- “帮我检查这章情绪够不够”
- “读者会不会有感觉”
- “这段是不是没情绪 / 不上头 / 太平”
- “帮我做小说情绪自检”
- “检查情绪线 / 情绪底层逻辑”
- “这场戏为什么不打动人”
- “改到读者能共情 / 心疼 / 憋屈 / 爽”
- 写完章节、场景、细纲后要求做质量检查

适用材料：

- 小说正文
- 短剧小说化正文
- 章节细纲
- 场景设计
- 爽文/虐文/修仙/都市/家庭打脸等通用网文片段

## 不适用边界

- 用户明确要求只改对话：优先使用 `v-novel-对话感情增强`。
- 用户明确要求全文去 AI 味或直接实改语言：优先使用 `v-novel-anti-ai`。
- 用户明确要求商业化立项评分：优先使用 `v-novel-商业化评测`。
- 用户明确要求拆样文机制：优先使用 `v-novel-chaiwen`。
- 用户明确要求从 0 做大纲排雷：优先使用 `v-novel-大纲排雷清单`。

本 skill 可以作为上述 skill 的后置检查，但不要替代它们的专门职责。

## 默认工作方式

默认不要输出空泛写作课。必须落到用户给出的具体文本或大纲上。

如果用户给的是正文：

1. 先判断每个关键场景的“读者情绪基线 → 结束情绪”。
2. 找出读者无感的原因：缺处境、缺在乎物、缺真实代价、缺行动驱动、情绪只靠内心独白、节奏一直紧或一直松。
3. 给出可执行修正：补哪一个处境、补哪一个具体在乎物、把哪句心理解释改成动作/对话/沉默。
4. 必要时提供一小段示范改写，但不要无边界重写全文。

如果用户给的是细纲/大纲：

1. 检查每个节点是否有“在乎物受威胁 → 情绪反应 → 行动选择 → 局势变化”。
2. 标出无情绪变化的水节点。
3. 补真实代价、未回答问题和紧松节奏。
4. 输出“改后情绪链”或“可直接扩写的场景抓手”。

## 读者情绪七道自检

### 1. 情绪基线是否变化

每一节/每一场进入前和结束时，读者情绪不能相同。

检查：

- 进入本节时，读者应该是什么情绪？
  - 好奇 / 心疼 / 憋屈 / 愤怒 / 担心 / 想看打脸 / 暂时放松 / 期待甜 / 害怕失去
- 结束时变成了什么？
  - 更心疼 / 更憋屈 / 更想看反击 / 暂时被安抚 / 新疑问被吊起 / 爽感释放 / 更不安
- 如果从头到尾都是同一种情绪，就是平。

最低合格：

```text
进入：读者以为【X】。
过程：看到【具体代价/选择/反应】。
结束：读者变成【Y】，并想继续看【未回答问题】。
```

### 2. 写的是“处境”，不是“事件”

事件本身不自动产生情绪。处境才让读者代入。

错误：

```text
他被人打了。
她被全家误会了。
宗门罚了主角。
```

合格：

```text
他想还手，但还手会丢掉母亲下个月的药费来源。
她明明能解释，却知道一开口妹妹就会被赶出家门。
宗门罚的不是灵石，而是他唯一能救师妹命灯的阵位资格。
```

检查问题：

- 主角如果行动，会失去什么？
- 主角如果不行动，又会失去什么？
- 这个损失是否足够具体？
- 读者是否能在自己生活经验里找到类似感受？

### 3. 情绪因果链是否完整

完整链条：

```text
角色在乎什么 → 在乎物受威胁 → 产生情绪 → 情绪驱动行动 → 行动改变局势
```

常见断点：

- 只写“他很生气”，没写他到底在乎什么。
- 只写“她很难过”，没写她失去了什么。
- 只写“他爆发了”，没写为什么现在不能再忍。
- 只写“她成长了”，没写她做了哪一个带代价的选择。

修正模板：

```text
【角色】最在乎【具体人/物/资格/尊严/承诺】；
现在【反派/局势】正在夺走【具体代价】；
他/她表面【克制反应】，但身体/动作暴露【真实情绪】；
最后他/她选择【行动】，导致【新的局势变化/更大问题】。
```

### 4. 危机代价是否真实

读者只会为真实代价紧张。

真实代价可以是：

- 钱、房子、工作、名额、资格
- 名声、脸面、话语权、选择权
- 亲密关系、被信任的资格、最后一次解释机会
- 命灯、阵位、宗门资源、师承资格、灵根/修为代价
- 证据、把柄、靠山、退路

不合格代价：

- “大家会误会他”但误会没有后果
- “他会很难过”但难过不影响选择
- “反派很生气”但生气不造成压迫
- “主角输了”但下一段立刻无成本翻盘

### 5. 情绪外化是否足够

不要连续三段内心独白。情绪必须能从动作、对话、沉默、身体反应、物件处理里漏出来。

优先使用：

- 手部动作：攥袖口、松开又握紧、拿错东西、把纸揉皱
- 身体滞后：先继续做事，过几秒才停下
- 对话断裂：没接话、改口、重复一句无关小事
- 沉默：最难受时不解释
- 物件：旧照片、药费单、阵牌、围巾、没送出去的东西

禁止默认依赖：

- 他很痛苦
- 她很崩溃
- 他心如刀割
- 她终于明白
- 他们都被震撼了

关键测试：

```text
删掉所有内心独白和情绪形容词后，读者还能不能感受到情绪？
能 = 好。
不能 = 情绪没有落地。
```

### 6. 节奏是否有紧松对比

连续紧绷会疲劳，连续松弛会塌。

推荐节奏：

```text
紧 → 松 → 紧 → 松 → 大紧 → 大松 / 新钩子
```

执行规则：

- 虐之前先给甜，读者才会痛。
- 爽之前先给压迫，读者才会爽。
- 愤怒之前先给忍耐，爆发才成立。
- 释怀之前先给执念，放下才有重量。
- 胜利之前至少给一次具体代价，赢才不是白给。

反模式：

- 一直哭、一直吼、一直惨。
- 一直赢、一直装、一直全场震惊。
- 刚有危机立刻解决，没有情绪发酵。
- 该让读者憋一下时，作者急着解释和安慰。

### 7. 结尾是否留下未回答问题

每个章节/场景结尾至少留下一个读者愿意追的问题。

可用问题类型：

- 真相型：当年的那件事到底是谁做的？
- 代价型：主角这次选择会丢掉什么？
- 关系型：对方是不是已经看懂了，却故意不说？
- 反击型：主角会怎么还回去？
- 升级型：反派下一步会怎么加码？
- 情绪型：这句没说完的话，下一场会不会爆？

不合格结尾：

- 把所有情绪都解释完。
- 把所有冲突都解决完。
- 用作者总结代替下一步钩子。

## 常见反模式与修正

| 反模式 | 问题 | 正确做法 |
| --- | --- | --- |
| 角色疯狂输出情绪 | 读者没有共鸣基础 | 先补处境和在乎物 |
| 连续三段内心独白 | 情绪只在脑内转 | 改成行动、对话、停顿、沉默 |
| 完美主角遇危机 | 读者不担心 | 给主角弱点和真实代价 |
| 连续紧绷不给喘息 | 读者疲劳 | 做紧松对比，给短暂希望再夺走 |
| 只写事件不写处境 | 读者无法代入 | 写“两难”和“不得不” |
| 只写惨不写选择 | 角色像受害工具 | 让情绪驱动一个带代价的行动 |
| 结尾全解释完 | 没有追读 | 留一个未回答问题 |

## 最终自检

交付前必须确认：

- 是否明确区分了“角色情绪”和“读者情绪”？
- 是否写出了情绪基线变化，而不只是评价“挺感人/不够感人”？
- 是否指出至少一个具体在乎物或真实代价？
- 是否把“事件”改成了“处境”？
- 是否避免空泛写作课，给了可执行修法？
- 如果给示范改写，是否用动作、对话、沉默、身体反应承载情绪，而不是心理解释？
