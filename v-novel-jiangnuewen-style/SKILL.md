# 《将虐文完成爽文，两个女主懵了》文风复刻 Skill

> 用途：供其他 Agent 在写新题材时，复刻本篇的叙事口吻、节奏、爽点结构、反虐逻辑和短篇爽文推进方式。
>
> 提炼来源：仅基于《将虐文完成爽文，两个女主懵了》这一篇，不引入其他作品经验。
>
> 适用题材：男频反虐、觉醒反杀、舔狗清醒、穿书改命、绿茶男/白月光/偏心亲属反噬、霸总/豪门/职场/家庭打脸、短篇一口气爽文。

---

## 0. 给 Agent 的直接调用指令

如果你是另一个写作 Agent，收到本文档后，请按下面指令执行：

```text
你现在模仿《将虐文完成爽文，两个女主懵了》的文风与爽文机制，写一个新的短篇爽文。

核心要求：
1. 第一人称男主视角，开篇直接把读者丢进极端委屈/逆天场面。
2. 原设定必须是“虐文/憋屈文/脑残剧情”，但主角觉醒后不忍、不解释、不求爱，直接用暴力、权力、财务、法律、舆论和现实后果反制。
3. 反派必须持续嘴硬、误判男主还在爱她/舔她/闹脾气，直到现实资源被切断，才逐步崩溃。
4. 节奏必须快：每 300-600 字至少有一次打脸、反转、羞辱、资源剥夺、围观审判或现实惩罚。
5. 语言要短、狠、直、口语化，有强烈吐槽感和情绪宣泄感。
6. 不写深情复合，不给反派体面，不用圣母原谅。结尾必须让反派彻底反噬，主角抽身享受新生活。
```

## 1. 一句话风格定位

**把原本让读者憋屈的虐文剧情，拆成一连串“当场反抽、资源断供、现实打脸、反派互咬、主角冷眼收割”的暴爽短篇。**

它不是细腻虐恋文，也不是讲道理的复仇文，而是：

- 读者刚开始被气到；
- 男主立刻替读者动手；
- 女主/养姐/绿茶男越嘴硬越丢脸；
- 她们每一次误判，都会马上变成更惨的现实后果；
- 最后原虐文的受害者不再受害，施害者被自己选择反噬。

---

## 2. 本篇的核心爽感机制

### 2.1 “虐文设定”先拉满血压

开篇不是慢铺设定，而是直接给一个荒唐到让读者冒火的场景：

- 男主刚出差回来；
- 妻子把他的总裁办公室送给绿茶小助理；
- 小助理故意露百万手表；
- 妻子反过来指责男主吓到助理；
- 男主还被要求理解、赎罪、下跪。

这种开局的作用：

1. **立刻制造读者站队**：读者不用思考，天然站男主。
2. **制造强烈不公**：资源、身份、尊严都被反派倒置。
3. **给后续反击提供合法性**：男主越狠，读者越觉得解气。

复刻时必须先设计一个“逆天到不能忍”的场景。

常用结构：

```text
我刚回来/刚醒来/刚进门。
本该属于我的东西，却被她送给了另一个男人/外人/白眼狼。
她还皱眉怪我不够大度。
绿茶反派一边装可怜，一边露出得意破绽。
我不解释，直接动手/断供/反制。
```

---

### 2.2 主角不是讲理型，是“读者代打型”

本篇男主的核心不是成熟稳重，而是**专门替读者出恶气**。

他的反应模式：

- 不哄；
- 不解释；
- 不自证；
- 不回忆旧情来软化；
- 不陷入雌竞/争宠；
- 直接把权力、钱、身份和拳头砸回去。

例如本篇反击链：

1. 办公室被抢 → 当场扇妻子。
2. 妻子嘴硬 → 再扇、再踹。
3. 绿茶插嘴 → 揪住狂扇。
4. 副卡被滥用 → 全部冻结。
5. 公司职位被寄生 → 全部辞退。
6. 医药费想赖账 → 让医院保安打绿茶。
7. 回家想继续住 → 保镖按住、签离婚、扔出去。
8. 求复合 → 拿职务侵占证据继续压。
9. 最后 → 让他们互相反噬，自己彻底抽身。

复刻原则：**每个反派动作，都必须引来一个更硬、更现实、更爽的回击。**

---

### 2.3 爽点不是“赢一次”，而是“连续剥夺”

本篇的爽点层层升级，不停从反派手里拿回东西：

1. **尊严层**：当众打脸、公开羞辱、拆穿绿茶。
2. **空间层**：拿回办公室、赶出家门。
3. **金钱层**：冻结副卡、不给医药费、追回手表。
4. **身份层**：辞退副总裁、辞退助理、官网通告。
5. **法律层**：离婚协议、职务侵占证据、报警威胁。
6. **关系层**：反派从“被宠爱”跌成“没人要”。
7. **命运层**：原本男主被害死，改成反派互害到底。

新题材复刻时，不要只写打脸，要写“资源剥夺链”。

推荐剥夺顺序：

```text
当场尊严 → 钱 → 职位/身份 → 住处/圈层 → 舆论/名声 → 法律/债务 → 反派内部互咬
```

## 3. 章节节奏模板

本篇是短篇分段式推进，每一小节承担一个明确爽文功能。

### 3.1 开篇钩子：3 秒内让读者血压升高

模板：

```text
我刚【回来/醒来/出院/下班】。
【妻子/未婚妻/姐姐/家人】却把我的【核心资源】送给了【绿茶/白眼狼/外人】。
她还反过来怪我。
绿茶露出得意破绽。
我直接反手处理。
```

要求：

- 第一段必须短。
- 第二段立刻出现荒唐事件。
- 第三到五段给绿茶和偏心者开口。
- 500 字内必须有第一次强反击。

本篇第一爽点是第 25 行左右的巴掌，非常早。

---

### 3.2 第 1 节：交代原剧情，但必须带吐槽

不是平铺背景，而是用“这是什么逆天剧情”的语气快速交代：

- 原主怎么被绿茶陷害；
- 两个女主怎么倒戈；
- 原主原结局多惨；
- 反派原结局多恶心；
- 主角为什么气到穿进来。

关键不是完整世界观，而是让读者明白：

**这个世界原本烂得离谱，所以男主接下来怎么狠都合理。**

可复刻句式：

```text
这是一个狗血到离谱的【题材】世界。
更狗血的是……
直到多年以后……她们才看清真相。
而真正的罪魁祸首却……啥事没有。
这 TM 是人能写出来的玩意？
```

---

### 3.3 中段：每个场景都要“反派嘴硬 → 主角现实制裁”

本篇中段几乎都采用同一高效循环：

```text
反派继续按旧认知发号施令
↓
主角冷眼看戏/短句吐槽
↓
反派提出荒唐要求
↓
主角当场反制
↓
旁观者/环境给出羞辱性反馈
↓
反派仍然误判“他只是吃醋/闹脾气”
↓
下一轮现实后果更重
```

典型场景：

- 医院刷卡失败；
- 大妈当众骂小情人；
- 保安追缴医疗费；
- 回家吃饭却被保镖按住；
- 签离婚协议；
- 被扔出唐家；
- 出租屋里被债主追；
- 回来求复合却被证据压死。

复刻时不要写空场景。每一场必须同时完成两个功能：

1. 让反派更丢脸；
2. 让男主拿回更多主动权。

---

### 3.4 后段：反派醒悟不能靠男主说教，要靠现实毒打

本篇不是男主苦口婆心证明自己，而是让她们自己掉进现实里：

- 没钱；
- 没工作；
- 没房子；
- 没朋友；
- 绿茶男暴露赌博、人渣、骗子本性；
- 她们被绿茶男反过来羞辱、殴打、威胁。

醒悟必须晚，且醒悟时已经没有价值。

复刻原则：

```text
反派不是被说服的，是被生活打服的。
她们不是悔悟后被原谅，而是悔悟后发现门已经关死了。
```

---

### 3.5 结尾：主角必须抽身享受，不沉迷复仇

本篇结尾的爽点不是主角站在尸体前感慨，而是：

- 反派彻底自毁；
- 男主在海边度假；
- 身边有新的女大；
- 生活轻松、性感、没负担；
- 用一句轻佻玩笑收尾。

这种结尾的本质：

**主角不是被仇恨困住的人，他赢了以后马上过好日子。**

复刻结尾模板：

```text
听到他们彻底完蛋的消息时，我正在【轻松享受新生活】。
阳光/海风/酒/新伴侣/新事业，形成强烈反差。
我只淡淡一笑，不再多看过去一眼。
```

## 4. 人物配置方法

### 4.1 男主：觉醒后的“高资源男主 + 情绪代打”

男主必须是爽文常见的高资源身份，不能设计成普通职员、普通上班族、普通人。现实题材只要求矛盾支点现实，不代表男主身份普通。

优先身份：

- 富豪 / 富二代 / 豪门继承人；
- 集团总裁 / 公司老板 / 控股股东；
- 家族产业实际掌权人；
- 有资产、有公司、有律师、有保镖、有财务团队的资源主；
- 表面恋爱脑、舔狗、被拿捏，实际资源都在他或他家手里。

禁止身份：

- 普通职员；
- 普通项目经理；
- 普通银行风控；
- 普通社区工作人员；
- 普通打工人；
- 只有一套房、只能靠流程慢慢维权的低资源男主。

执行原则：

```text
矛盾可以现实：房产加名、婚姻财产、欠薪、继承、职场背锅、物业纠纷。
男主身份必须爽：有钱、有权、有资源、有执行力。
```

男主必须具备两类力量：

1. **情绪力量**：敢骂、敢打、敢断，不怕关系破裂。
2. **现实力量**：有钱、有权、有律师、有保镖、有公司、有证据，能够让反派的高位幻觉马上付出现实代价。

男主的口吻：

- 第一人称；
- 口语化；
- 带脏话和吐槽；
- 情绪直接外露；
- 对反派没有温柔滤镜。

常用表达：

```text
我差点气笑了。
听听，这就是 TMD 逆天发言。
我懒得跟她废话。
有意思。
这场游戏才刚刚开始。
```

男主行为准则：

- 不争宠，只判刑。
- 不吃醋，只断供。
- 不解释，只执行。
- 不复合，只追责。
- 不留情，只收割。

---

### 4.2 女主/养姐：高位幻觉型白眼狼

她们不是普通坏，而是有一种“我理所当然占有你一切”的高位幻觉。

核心特征：

- 吃男主的、喝男主的、用男主的钱，却看不起男主；
- 把男主的付出当成义务；
- 把偏袒外人包装成善良、赎罪、大度；
- 遇到反击后第一反应不是害怕，而是愤怒和不可置信；
- 反复误判男主还在舔她们。

她们的固定台词逻辑：

```text
你怎么能这么对我？
你不就是吃醋吗？
你闹够了没有？
你赶紧道歉/结账/低头。
我真的生气了。
你以后跪下求我，我都不会回头。
```

复刻关键：

- 她们必须嘴硬很久；
- 她们越嘴硬，现实越打脸；
- 她们求饶时，读者不能心软，只能觉得“晚了”。

---

### 4.3 绿茶男/外来反派：卖惨型寄生虫

谢怀安的作用不是强反派，而是“引爆两个女人愚蠢”的催化剂。

核心手法：

- 装可怜；
- 自伤陷害；
- 一口一个“都是我的错”；
- 暗地里得意；
- 实际好赌、贪财、懒惰；
- 失去保护后立刻撕破脸。

常用台词模板：

```text
都是我的错。
你要怪就怪我吧。
我还是走吧。
我知道你不喜欢我。
你这样只会把她们推得越来越远。
```

后期反噬台词要彻底翻脸：

```text
你们以为自己是什么好东西？
我不过是卖卖惨，你们还真信了。
一个【身份 A】，一个【身份 B】，装什么大小姐？
现在只有一条路，回去跪下求他继续当冤大头。
```

---

### 4.4 围观群众/下属：负责公开审判

本篇很会利用旁观者扩大爽感：

- 公司员工捂嘴震惊；
- 医院大妈骂“小情人”；
- 医院负责人拆穿装病；
- 管家、保镖执行男主命令；
- 官网通告封死名声。

这些角色的作用：

1. 把私人冲突公开化；
2. 让反派不只是被男主打脸，而是被世界打脸；
3. 证明男主不是疯，是反派真的不要脸。

复刻时，每个大场景最好安排一个旁观审判位：

```text
公司员工 / 医院大妈 / 保安 / 管家 / 亲戚 / 同学 / 网友 / 警察 / 律师 / 财务 / 物业
```

## 5. 语言风格复刻

### 5.1 句子要短，转折要硬

本篇大量使用短句和独立段落：

```text
我笑了。
有意思！
我差点气笑了。
时间停滞了一秒。
这场游戏才刚刚开始。
```

写作要求：

- 不要长段抒情；
- 不要复杂比喻；
- 一句话只承载一个动作、一个情绪或一个打脸点；
- 爽点句单独成段。

---

### 5.2 口语脏话是情绪阀门，不是无意义堆砌

本篇脏话出现的位置通常是：

- 反派发言太逆天；
- 主角准备动手；
- 主角拆穿荒唐逻辑；
- 爽点即将兑现。

常用风格词：

```text
TM、卧槽、妈的、什么东西、贱人、白眼狼、寄生虫、蠢货、死绿茶
```

使用原则：

- 可以狠；
- 但要跟着事实打脸走；
- 不要每句都骂，重点处骂才有冲击。

---

### 5.3 对话要像吵架，不像说明书

本篇对话的特点：

- 反派先情绪化命令；
- 男主用反问拆穿；
- 反派继续高位压迫；
- 男主直接执行惩罚。

好用句式：

```text
“你凭什么？”
“你是不是疯了？”
“你不就是吃醋吗？”
“你闹够了没有？”
“有本事你就签。”
“哪一样不是花我的钱买的？”
“你们不是知道错了，而是走投无路了。”
```

避免：

- 长篇解释世界观；
- 人物用理性论文式发言；
- 男主反复自证清白；
- 反派过早承认错误。

---

### 5.4 喜剧化反差削弱血腥感，增强爽感

本篇虽然有大量暴力和惩罚，但经常用轻佻、吐槽、夸张旁观来转成爽文喜剧感：

- 烟灰缸砸错人后，男主说“满意相当满意”“666”；
- 医院大妈当场吐槽“小情人”；
- 结尾女大撒娇，男主轻佻回应。

复刻时可以使用：

```text
误伤反派 / 围观吐槽 / 反派装逼失败 / 主角看戏 / 轻飘飘补刀
```

注意：喜剧不是卖萌，而是让反派更滑稽、更丢脸。

---

### 5.5 Canvas 补充：动作先行，立场后置

同目录 `写作风格.canvas` 里有一条很关键：**主角不用急着说话，用神情和行动先把立场打出来，行动后再表达态度。**

复刻时不要让主角先长篇辩论。

更有效的顺序是：

```text
反派说逆天话
→ 主角看着对方，先给一个很短的心理/神情反应
→ 主角直接行动教训/断供/夺回资源
→ 行动造成现场变化，引出外人围观
→ 主角再用一句狠话定性
```

示例节奏：

```text
我看着她。

她眼底那点理所当然，几乎要溢出来。

我没再废话。

抬手就是一巴掌。

等她捂着脸踉跄后，我才笑了笑：
“现在能听懂人话了吗？”
```

要点：

- **先动作，后台词**，爽感更硬。
- 主角的狠话必须跟着已发生的行动落下，不要空喊。
- 反派越想用旧关系压人，主角越要用新行动打破旧秩序。

#### 5.5.1 防偏差：动作先行 ≠ 冷静克制

执行本风格时，最容易出现的偏差是：把“主角不用先解释、先用行动表态”误写成“主角冷静、克制、理性、律师式处理”。这是错误方向。

本篇主角不是冷静律师型，而是**情绪代打型主角**：

```text
逆天女频发言
→ 主角被气笑 / 血压上来 / 戾气外露
→ 主角直接动作
→ 现场炸开
→ 主角狠话定性
→ 立刻接现实反制
```

正确理解：

- 主角不解释，不是因为他情绪稳定，而是因为对方的“逆天女频发言”已经不配听解释。
- 主角先行动，不等于动作温和；动作要有火气、有冲击、有现场后果。
- 主角可以骂、可以气笑、可以上头、可以爆粗、可以拍桌、撕协议、甩文件、踹椅子、打电话断供、叫律师、叫保安。
- 但主角不能只无效发疯；怒气必须马上转成有效动作和现实反制。
- 每次爆发后，都要让反派损失一点东西：脸面、钱、资格、资源、话语权、体面或安全感。

错误写法：

```text
我看着协议。
没说话。
把协议合上。
“这是离婚，还是抢劫？”
```

问题：太冷，像律师调解，不像本篇主角。

正确写法：

```text
我看着协议上那几行字。

房子归她。
贷款我还。
我还要补她八十万。

我差点当场笑出声。

真他妈开眼了。

我爸妈省吃俭用二十年凑出来的首付，她嫁进来八个月，房贷没还几期，倒先学会把我家房子往自己名下扒拉。

这不是离婚协议。

这是抢劫计划书。

我抬手抓起协议，直接甩在她脸上。

“啪！”

纸页砸得她猛地偏过头。

“房子归你，贷款我还，还补八十万？”

“林晚晴，你们家这是离婚，还是组团入室抢劫？”
```

执行口诀：

```text
不冷静，不自证；先上头，后反制。
怒气要落地，爆发要有账。
```

### 5.6 Canvas 补充：眼神和行动冲突

绿茶和保护伞的“虚伪感”，不要只靠作者说他虚伪，要用**眼神和动作互相打架**写出来。

典型公式：

```text
表面动作：慌张、后退、红眼、服软、说都是我的错。
真实破绽：得意眼神、嘴角压不住、故意露出资源符号、朝主角挑衅。
```

示例：

```text
他给了我一个得意的眼神，又慌慌张张站起来。

“唐总，都是我的错，我不配坐您的位置。”
```

这种写法比直接说“他很绿茶”更有效，因为读者能自己看见他的表演。

#### 5.6.1 防偏差：绿茶不是普通委屈，必须“很能装”

执行本风格时，绿茶不能只写成“哭、委屈、说自己没安全感”。这太浅，像普通受害者，不像本篇的绿茶。

绿茶的核心不是单纯卖惨，而是：**表面退让，实际递刀；嘴上自责，行动占便宜；看似替主角说话，实则把主角架到坏人位置。**

绿茶必须同时完成三层动作：

```text
第一层：装退
“都是我的错 / 我不要了 / 我还是走吧 / 你别为了我吵架”

第二层：递刀
故意把核心利益、伤口、道德压力说出来，让保护伞接着骂主角。

第三层：露破绽
眼神得意、手按住协议、故意不拿走东西、嘴角压不住、余光看主角反应。
```

正确的绿茶台词不是直接索取，而是把索取包装成“我不配”：

```text
“算了，妈，别说了。”
“房子我不要了，真的。”
“反正我嫁进来这八个月，也没真的被当成一家人。”
“周叙要是觉得我不配有这个名字，那就删掉吧。”
“我出去租房也可以，没关系的。”
```

这类台词的真实作用不是退让，而是逼保护伞开喷：

```text
保护伞听完立刻心疼：
“你听听！她都被你逼成什么样了？”
“她不要房子？她凭什么不要？房本上本来就有她名字！”
```

绿茶动作必须和台词冲突：

```text
嘴上说不要房子，手却按着离婚协议不松。
嘴上说别吵了，眼睛却看向保护伞，等对方替她出头。
嘴上说自己可以搬出去，行李箱却堵在主卧门口。
嘴上说都是自己的错，实际每句话都在暗示主角冷血、计较、没担当。
```

错误写法：

```text
“我只是没有安全感。”
“你能不能给我一点体面？”
```

问题：只是委屈，不够装，没有递刀，也没有引爆保护伞。

正确写法：

```text
林晚晴低头把协议往回收了一点。

“算了，妈。”

她声音很轻，轻得像真被我欺负狠了。

“他不愿意就算了。”

“反正这房子本来也不是我买的。”

“房本上那个名字，就当我自己不懂事，非要来的。”

她说着要收协议，手指却死死按在最后一页签名处。

丈母娘果然炸了。

“什么叫你不懂事？”
“林晚晴，你给我坐好！”
“房本上有你的名字，那就是你的！”
```

执行口诀：

```text
绿茶要装退，不是真退。
嘴上让，手上占；眼里怯，心里等人替他咬。
每一句“我不要了”，都要变成保护伞开喷的引线。
```

### 5.7 Canvas 固定关键幕节奏

本节奏来自同目录 `写作风格.canvas`，是本风格的固定骨架。用户要求“按 Canvas 节奏 / 下一幕 / 下一章 / 继续写”时，必须严格按下面顺序推进，不能跳幕、合并错位、提前终局、提前求复合、提前内讧，也不能推翻上一幕已发生结果。

#### 固定关键幕

```text
导语：冲突开头
1. 介绍背景
2. 保护伞开喷，绿茶拱火，主角开打，众人围观
3. 第二个保护伞出场，出手偷袭，结果命中绿茶；一起离场救治
4. 冻结资源，反击
5. 收到通知气炸；回忆舔狗；放女频毒药；看主角能坚持几天？
6. 断资源的尴尬场景；意外重逢，对峙冲突；引入三方围观
7. 保护伞与三方吵架；三方也不是吃素的。主角还是直接动手，得到三方肯定。保护伞们还以为我闹情绪，还说一大段自以为是。赶紧离开丢人现眼的场面。
8. 施压；破产清算。
9. 好不容易回家了，又出幺蛾子，带着绿茶继续闹，如想住家里照顾
10. 自寻死路；主角把分割协议弄好（如果不签就走证据流）；这里的爽点是保护伞还以为主角在闹，一心威胁主角，让主角别后悔，果断签了
11. 彻底解除关系后；男主彻底翻脸，直接划清界限；保护伞一群感觉不对，却毫无办法
12. 绿茶们开始了艰难处境；保护伞这时候也发现绿茶的重大问题
13. 保护伞们开始内讧、后悔；现实开始压迫他们。
14. 保护伞求男主求复合；男主不理她们
15. 最后一刀；之前没用到的证据链这里用上；再次逼迫
16. 保护伞们凄惨下场和男主符合身份的结尾
```

#### 每幕执行边界

- **导语**只开冲突，不展开完整第一幕；必须短、狠、有逆天事件、有绿茶装退、有保护伞第一句逆天发言、有主角第一下反应。
- **1**只补必要背景，不抢 2 的冲突，不长篇解释。
- **2**必须完成保护伞开喷、绿茶拱火、主角直接行动、外人围观。
- **3**必须让第二保护伞升级冲突，最好自以为帮绿茶，结果误伤 / 反噬绿茶；不能写成普通吵架。
- **4**只做资源冻结和反击落地：停卡、删门禁、撤权限、赶人、查账、收回资源；不能提前离婚求复合。
- **5**写保护伞阵营收到通知后气炸、回忆主角以前舔狗、放女频毒药、误判主角坚持不了几天；不能让绿茶过早撕脸。
- **6**写断资源后的尴尬场景和意外重逢，引入三方围观；不能推翻前幕结果。
- **7**写保护伞和三方吵，三方不是吃素的；主角继续直接行动，得到三方肯定；保护伞仍误判主角只是闹情绪，狼狈离场。
- **8**写施压和破产清算，现实账单、资源、身份开始压下来，但还不写彻底求复合。
- **9**写保护伞好不容易回到某个安全场域，又带绿茶继续出幺蛾子，试图住进来、照顾、占位或继续绑定主角资源。
- **10**写自寻死路：保护伞以为主角还在闹，威胁主角别后悔，反而把分割协议 / 证据流推进到可执行状态。
- **11**写彻底解除关系：男主翻脸划清界限，保护伞感觉不对但毫无办法；不能写成法务发布会，台词要短狠。
- **12**写绿茶艰难处境，保护伞开始发现绿茶问题；绿茶仍可装，但现实裂缝必须出现。
- **13**写保护伞内讧、后悔，现实继续压迫他们；绿茶可开始露出真实怨气。
- **14**写保护伞求复合，男主不理；不能让男主心软。
- **15**写最后一刀，把之前没用到的关键证据链压上来，再次逼迫、彻底断幻想。
- **16**写保护伞凄惨下场和男主符合身份的新生活结尾；男主必须仍是高资源爽文身份，不降级成普通人守房。

#### 顺序硬规则

```text
当前幕没有完成，不许跳下一幕。
上一幕已经发生的结果，不许在下一幕推翻。
没有到 12-13，不许让绿茶彻底撕脸。
没有到 14，不许求复合。
没有到 11，不许彻底解除关系。
用户说“下一幕”，默认只写当前顺序的下一幕正文，不解释结构。
```

### 5.8 Canvas 补充：保护伞负责拉仇恨，绿茶负责拱火

角色功能要分清：

- **绿茶**：服软、看菜下碟、制造自己委屈的人设；第一次冲突中负责拱火。
- **绿茶的保护伞**：主表达者，负责拉仇恨，复述“逆天女频发言”，让主角道歉，认定绿茶可怜善良。
- **第二个保护伞**：升级冲突，甚至可以直接偷袭主角，但最好制造戏剧性误伤，让绿茶反受其害。

常用链条：

```text
绿茶装可怜
→ 保护伞心疼地看着绿茶
→ 保护伞把荒唐要求说出口
→ 主角直接行动教训
→ 外人围观
→ 第二保护伞出手升级
→ 误伤/反噬绿茶
→ 保护伞反过来怪主角
```

这一套可以把“逆天感”堆得很快，适合短篇开头。

#### 5.8.1 防偏差：人物功能不能写成泛化爽文套路

执行本风格时，如果只记住“主角反击、绿茶卖惨、保护伞拉仇恨、围观者审判”，很容易写偏。必须按下面的人物执行边界处理。

##### A. 男主偏差：不能写成冷静律师，也不能写成无效疯狗

错误偏差：

- 过于冷静，像律师调解；
- 只讲证据，不冒火；
- 只发疯骂人，没有现实反制；
- 长篇解释自己为什么委屈；
- 被反派带进“你爱不爱我 / 你是不是男人”的自证。

正确执行：

```text
逆天女频发言先把男主气到上头
→ 男主直接动作打断旧秩序
→ 动作后用短句定性
→ 马上接一个现实反制：断供、撤权限、叫律师、亮流水、查证据、赶人、冻结资源
```

男主台词要像巴掌，不像演讲：

```text
“谁写的？”
“你再说一遍。”
“这叫让步？”
“别拿安全感遮丑。”
“想要房？行，账先摊开。”
“我爸妈的钱，不是你们家的提款机。”
```

##### B. 绿茶偏差：不能只委屈，必须装退递刀

错误偏差：

- 只哭、只说没安全感；
- 直接索取核心利益，显得太蠢；
- 台词像普通受害者，没有绿茶手法；
- 没有眼神/动作破绽；
- 没有把保护伞引爆。

正确执行：

```text
嘴上退：我不要了 / 算了 / 都是我的错
手上占：按住协议 / 不拿走东西 / 堵住门 / 继续坐在资源位置上
话里递刀：把“我不配、他没把我当一家人、我可以搬出去”说给保护伞听
眼里露破绽：余光看保护伞、看男主反应，委屈里藏笃定
```

绿茶不是直接说“我要房”，而是说：

```text
“算了，妈，别说了。”
“他不愿意就算了。”
“反正这房子本来也不是我买的。”
“房本上那个名字，就当我自己不懂事，非要来的。”
“我出去租房也可以，没关系的。”
```

##### C. 保护伞偏差：不能写成网感反派，要写成熟人伦理压迫

错误偏差：

- 台词太像短剧金句或网上吵架；
- 一上来就把真实目的说透；
- 像陌生人辩论，不像熟人压迫；
- 只会骂，不会借“长辈、女人、体面、名声、家庭”压主角；
- 没有心疼绿茶的动作。

正确执行：保护伞负责把绿茶递出来的刀，变成“逆天女频发言”。

常用压迫口吻：

```text
“小周，阿姨说句不好听的。”
“话不能这么说。”
“你爸妈也是明事理的人。”
“晚晴是女孩子。”
“她跟你一场，现在出去别人怎么说她？”
“你房子没了还能挣，她呢？”
“你让一步，大家都好看。”
```

保护伞说话要像“我站在道德高处替她主持公道”，不是像“我要抢你房”。

##### D. 第二保护伞偏差：不能太聪明，不能讲大道理

错误偏差：

- 写成逻辑清晰的副辩手；
- 台词太完整、太像作者总结；
- 只负责复述保护伞观点，没有升级动作；
- 没有犯浑、抢东西、推笔、堵门、动手等具体行为；
- 没有制造“误伤绿茶 / 反暴露证据”的戏剧性。

正确执行：第二保护伞要更冲、更欠、更没耐心，负责把局面推炸。

```text
“差不多得了。”
“签了不就完了？”
“我姐都这样了，你还想怎么着？”
“你一个大男人，别磨叽。”
“有意思吗？”
```

行动优先于道理：

```text
推笔、抢协议、抢材料、堵门、拍桌、伸手拦人、威胁主角别把事闹大。
```

最好让他自以为帮绿茶，结果误伤绿茶：

```text
抢文件 → 把加名后咨询离婚分房的截图抖出来
拍桌逼签 → 让调解员注意到协议里“房子归女方、贷款男方还”的荒唐条款
堵门闹事 → 引来物业/邻居/保安围观
```

##### E. 围观者/规则方偏差：不能只震惊，必须给现实反馈

错误偏差：

- 只写“众人震惊”；
- 围观者统一倒戈，显得廉价；
- 调解员/律师/银行柜员像主角外挂；
- 规则方替主角骂人，失去现实感。

正确执行：围观者和规则方不一定站主角，但必须让反派体面受损、局势变化。

```text
调解员：从劝和到皱眉追问关键时间点。
律师：发现当事人隐瞒事实后改口提示风险。
银行柜员：不评价家务事，只提示账户需要双方确认。
邻居/亲戚：一开始看热闹，看到流水后不敢附和。
物业/保安：不讲大道理，只按规则阻止闹事。
```

规则方台词要克制，但能扎到反派：

```text
“林女士，这个咨询时间，是加名后的第三天？”
“这个情况，你之前没有向我说明。”
“女士，这笔转账需要双方确认。”
“如果涉及纠纷，建议你们走正式程序。”
```

##### F. 现实题材适配偏差：矛盾现实，不等于男主普通

把本风格迁移到现实新闻/法院案例类主题时，不能把男主降级成普通职员、普通银行风控、普通打工人。**现实感来自矛盾和规则支点，不来自男主低资源。**

正确方向：

```text
房产加名现实 → 男主可以是家族地产/集团继承人，房子是资产边界，不是唯一命根子。
欠薪现实 → 男主可以是控股老板/投资方/集团少东家，反制恶意承包商或蛀虫管理层。
继承现实 → 男主可以是豪门继承人/家族产业掌权人，反派抢的是家族资产与身份位。
职场背锅现实 → 男主可以是董事长儿子/隐名股东/集团监察负责人，反派误以为他只是普通员工。
物业纠纷现实 → 男主可以是小区大业主/开发商继承人/物业公司实际控股方。
```

强爽动作仍要根据现实题材替换，但男主必须有高资源执行力：

```text
扇巴掌 → 甩协议 / 拍桌 / 摔笔 / 当场拒签 / 必要时直接动手制造爽点
保镖扔人 → 保镖/物业/安保拦人 / 换锁留证 / 报警留记录
冻结副卡 → 停止共同账户转出 / 撤销授权 / 关闭亲属代扣 / 冻结附属卡
辞退职位 → 撤回项目权限 / 取消担保 / 解除代持 / 终止调解 / 董事会撤职
官网通告 → 亲戚群贴证据 / 律师函 / 调解记录 / 判决结果 / 公司公告
```

现实题材也要保留火气，但火气要落在高资源男主能立刻执行的动作上。

##### G. 台词偏差：不能太工整，必须像熟人现场互相压

错误偏差：

- 每句都像金句；
- 人物轮流演讲；
- 反派把动机说得太清楚；
- 主角把证据链解释成报告；
- 台词没有打断、吞话、旧账、称呼和熟人压迫。

正确执行：

```text
长句拆短。
熟人用称呼压人：小周、姐夫、晚晴、阿姨说句不好听的。
反派不说“我要你的钱”，说“你不能让我什么都没有”。
主角不讲完整法理，抓一句最恶心的话反抽。
```

##### H. 每场人物自检

写每一场前，按下面检查：

```text
绿茶有没有装退递刀？
保护伞有没有把刀接过去，复述逆天女频发言？
第二保护伞有没有用动作升级，而不是讲大道理？
男主有没有先被气到，再用有效动作反制？
围观者/规则方有没有带来现实反馈，而不是只震惊？
本场有没有让反派损失一项东西：脸、钱、资格、资源、话语权、体面、安全感？
台词像不像熟人在现场互相压，而不是作者替他们总结？
```

##### H.1 交付前强制自检门禁：不通过就重写，不让用户提醒

执行本风格时，不能把“自检”当成文档里的装饰。每次用户要求“写导语 / 下一幕 / 下一章 / 继续写”时，输出正文前必须在内部完成硬性门禁；任一项不通过，必须先自行重写，不能把问题稿交给用户再等用户提醒。

强制门禁：

```text
1. 节奏门禁：是否严格处在 Canvas 当前节点？有没有跳幕、提前终局、提前求复合、提前内讧、推翻上一幕结果？
2. 连续性门禁：上一幕已经发生的结果有没有被本幕否定？例如已经退婚，就不能再让女方催取戒指。
3. 人物功能门禁：绿茶是否装退递刀；保护伞是否接刀开喷；第二保护伞是否动作升级；男主是否情绪上头后有效反制？
4. 男主身份门禁：男主是否仍是高资源爽文身份，不能被写回普通人或低资源维权者。
5. 台词门禁：台词是否像熟人现场互相压；有没有太工整、太发布会、太法务、太作者总结？
6. 正文门禁：有没有解释句型、幕间说明腔、结构分析句？用户要正文时只能交正文。
7. 爽点门禁：本幕有没有至少一个落地后果：停卡、门禁、丢脸、退婚、赶人、断供、证据曝光、权力收回。
8. 绿茶门禁：绿茶有没有嘴上不要、手上占；有没有“我不配 / 算了 / 别为了我”这种递刀；不能只普通委屈。
9. 保护伞门禁：保护伞有没有把荒唐要求包装成亲情、体面、女人难处、娘家尊严；不能只骂街。
10. 语气门禁：男主有没有气笑、上头、短句反抽；不能冷静律师，也不能无效疯狗。
```

交付规则：

```text
不输出自检过程。
不向用户解释“我检查了”。
只把通过门禁后的正文交出去。
如果写完发现不通过，立刻删掉重写。
```

失败警告：

```text
如果用户指出“节奏不对 / 台词不对 / 绿茶不够装 / 又解释了 / 连续性错了”，说明本门禁执行失败。必须立刻承认，不辩解，并把遗漏项补回 skill。
```

##### I. 正文防偏差：禁止解释句型和幕间说明腔

执行本风格写正文时，不能把创作思路、结构判断、幕次功能写进正文或回复里。用户要“下一幕/写正文”时，直接进入场景，不要先解释“这一幕应该写什么”。

错误偏差：

- 用大量“这一幕只做一件事 / 下一幕必须进入 / 这里应该 / 不能写 / 这算作”来解释结构；
- 正文里用旁白说明人物功能，如“他这是在递刀”“她作为保护伞开始误判”；
- 用总结句替代动作和台词，如“女方阵营第一次真正感受到资源被切断”；
- 写成编剧拆解、剧情说明、复盘报告，而不是小说正文。

禁止句型：

```text
这一幕应该……
这一幕只做……
这里的作用是……
这说明……
他/她的功能是……
这就完成了……
这可以算作……
不能写……要写……
接下来进入……
核心不是……而是……
```

正确执行：

```text
直接写场景。
用手机短信、门禁提示、副卡刷卡失败、保镖动作、人物吵架来呈现资源切断。
用绿茶的装退、保护伞的逆天女频发言、男主的上头反制来推进。
读者能从场面看懂，不需要作者解释。
```

正文自检：

```text
删掉所有“这一幕/这里/作用/说明/功能/算作”的说明句。
删掉所有替读者总结人物动机的句子。
保留动作、对话、物件、通知、账单、现场反应。
如果一句话像写作提纲，就改成场景里的一个动作或一句台词。
```

---

### 5.8 Canvas 补充：废话文学要变成情绪拉扯

这里的“废话文学”不是水字数，而是让反派把利己逻辑反复包装成道德正确。

写法：

```text
利己主义的话
→ 主角心理复述，点出荒唐
→ 反派嘴上再复述一遍，继续加码
→ 主角行动打断
```

示例：

```text
她说得理直气壮。

花我的钱，养她的小助理，还要我感谢她替我赎罪。

听听。

这就是她嘴里的大度。

我被气笑了。
```

注意：反派可以重复“你就是吃醋、你闹够没有、你不够大度”，但每次重复之后都要换来更重的现实后果，不能原地空转。

---

### 5.9 Canvas 补充：时间定住写法

遇到误伤、公开处刑、重大反转时，可以短暂“定格”，然后一个人一个人写过去。

公式：

```text
动作爆发
→ 声音/撞击/碎裂
→ 时间停了一秒
→ 绿茶的惨状
→ 保护伞的懵
→ 围观者的反应
→ 主角轻飘飘补刀
```

用途：

- 放大戏剧性；
- 让读者看清每个人的狼狈；
- 给主角补刀制造舞台。

## 6. 场景设计方法

### 6.1 每个场景必须有“旧秩序崩塌”

本篇所有爽点都建立在旧秩序崩塌上：

- 以前总裁被副总裁训得像儿子 → 今天当众扇她；
- 以前她们随便刷副卡 → 今天医院刷不出来；
- 以前她们在唐家像主人 → 今天被保镖扔出去；
- 以前她们笃定男主舔她们 → 今天跪下也没用。

新题材场景设计时，先写清旧秩序：

```text
以前她们可以随便命令我。
以前她们花我的钱从不问一句。
以前她们只要皱眉，我就会低头。
```

然后当场反转：

```text
但这一次，我没有动。
我只是笑了笑，按下了电话。
```

---

### 6.2 强制公开处刑

爽文打脸最好发生在公共空间：

- 办公室门没关；
- 公司员工都在看；
- 医院大厅有人围观；
- 别墅有佣人、保镖、管家；
- 公司门口下班高峰；
- 官网公告。

公开空间的作用：

1. 反派的体面被剥掉；
2. 男主的地位被重新确认；
3. 读者有“全世界都看见了”的爽感。

复刻时，不要总写密室对峙。尽量把打脸放到：

```text
宴会 / 公司会议 / 医院大厅 / 家族聚餐 / 婚礼现场 / 直播间 / 学校礼堂 / 商场 / 警局门口
```

---

### 6.3 道具必须带资源意味

本篇道具不是装饰，而是资源符号：

- 总裁办公室 = 权力位置；
- 百万手表 = 男主资源被绿茶占用；
- 副卡 = 金钱供养关系；
- 离婚协议 = 关系切割；
- 职务侵占证据 = 法律追责；
- 别墅大门 = 阶层边界。

复刻时每个关键道具都要能被“夺回/冻结/摔碎/公开/追回”。

道具模板：

```text
房产证、黑卡、公司印章、股份协议、订婚戒指、豪车钥匙、医疗账单、律师函、监控录像、直播回放、转账记录、奢侈品、职位任命书
```

---

## 7. 爽点排列公式

### 7.1 反虐短篇总公式

```text
极端憋屈开局
→ 主角觉醒/穿书/知道原结局
→ 当场硬反击
→ 反派误判：他只是吃醋/闹脾气
→ 主角切断资源
→ 反派继续嘴硬
→ 公共场合丢脸
→ 主角用法律/财务/权力补刀
→ 反派内部开始互咬
→ 反派求原谅
→ 主角指出她们不是悔悟，是走投无路
→ 最后一击：债务/证据/公告/报警
→ 反派彻底反噬
→ 主角享受新生活
```

---

### 7.2 单场景爽点公式

```text
1. 反派提出荒唐要求。
2. 男主先短暂看戏或气笑。
3. 反派用旧关系压男主。
4. 男主一句话拆穿资源真相。
5. 直接执行惩罚。
6. 旁观者补刀。
7. 反派震惊、愤怒、嘴硬。
8. 男主留下下一轮更狠的后果。
```

示例骨架：

```text
她皱眉：“你闹够了没有？赶紧把钱付了。”
我差点气笑。
“我冻结自己的卡，关你什么事？”
她脸色一僵。
周围人已经开始窃窃私语。
我拿出手机，拨通律师电话。
“通知财务，从今天起，停止她名下所有副卡权限。”
```

---

## 8. 反派误判链

本篇反派一直靠误判推动剧情：

1. 以为男主不敢动手；
2. 以为男主打人只是吃醋；
3. 以为辞退只是引起注意；
4. 以为冻结卡只是闹脾气；
5. 以为离婚协议是以退为进；
6. 以为男主还会跪下求她们；
7. 直到没钱、没工作、没房、被绿茶打，才意识到完了。

复刻时必须保留这种“延迟醒悟”。

反派越晚醒，读者越爽。

但注意：误判不能没有代价。每一次误判后，都要让她们失去一样东西。

---

## 9. “悔悟”写法

本篇的悔悟不是温情戏，而是羞辱戏。

她们求原谅时，男主重点指出：

```text
你们不是知道错了，而是走投无路了。
```

这是全文关键逻辑。

复刻时，反派求饶必须满足：

- 形象已经狼狈；
- 资源已经失去；
- 绿茶已经暴露；
- 她们不是因为良心发现，而是因为没路了；
- 男主必须明确拒绝，并进一步补刀。

求饶场景模板：

```text
她们终于跪在我面前，哭着说知道错了。
我没有半点心软。
我只是把过去她们做过的事，一件件摆在她们面前。
然后告诉她们：
“你们不是后悔伤害我，你们只是后悔自己没了退路。”
```

## 10. 禁忌与避坑

### 10.1 不能让男主重新心软

这类文的读者来看的是清算，不是复合。

禁止：

- 女主哭几句就原谅；
- 男主回忆过去开始动摇；
- 反派洗白成“只是被蒙蔽”；
- 结尾暗示复合；
- 男主替反派兜底。

可以写回忆，但回忆只能服务于“她们更白眼狼”，不能服务于“她们其实也爱男主”。

---

### 10.2 不能只打嘴炮，不给现实惩罚

本篇爽点强，是因为每次嘴炮后都有现实后果：

- 扇巴掌；
- 冻卡；
- 辞退；
- 医院扣人；
- 保镖扔出门；
- 官网通告；
- 职务侵占证据。

复刻时，如果男主只是骂赢了，但反派没损失，爽感会塌。

---

### 10.3 不能让反派太聪明

这类文反派的爽点来自“自以为聪明，实则蠢到离谱”。

她们必须反复高估自己在男主心里的位置，低估男主切割的决心。

但绿茶男后期可以突然撕破脸，因为他承担“真相揭露”和“内部反噬”的功能。

---

### 10.4 不能铺太久

本篇每个场景都很快进入冲突。

写新题材时避免：

- 大段介绍公司背景；
- 详细解释商业流程；
- 男主内心独白超过动作；
- 反派长篇卖惨但没人打断；
- 爽点延迟太久。

---

## 11. 可直接套用的新题材骨架

### 骨架 A：豪门未婚妻把婚房给白月光

```text
我刚从国外谈完百亿合同回来。
未婚妻却把我亲手买的婚房，改成了她白月光的康复房。
白月光躺在主卧里，戴着我送她的订婚戒指改的项链，眼眶发红地说自己不配。
未婚妻让我别小气，说他只是病人。
我当场让人拆了婚房，冻结她所有副卡，取消婚礼，公开退婚。
她以为我在吃醋，直到她家公司资金链断裂，才跪在我楼下求我。
```

### 骨架 B：家人把公司股份送给养子

```text
我刚从 ICU 醒来。
父母和妹妹已经把我名下股份转给了他们收养的好弟弟。
养子红着眼说自己只是想替我分担。
妹妹骂我冷血，父母让我懂事。
我直接调监控、请律师、报警，切断全家生活费。
他们以为我只是争宠，直到被养子卷钱跑路，才想起我这个亲儿子。
```

### 骨架 C：妻子用我的钱养男大学生

```text
我刚结束三个月封闭项目。
妻子却带着男大学生住进我买的别墅，还让他睡我的主卧。
男大学生穿着我的睡袍，戴着我表柜里的限量表，说自己马上搬走。
妻子皱眉怪我吓到他。
我当场让保镖把人扔出去，冻结所有卡，发律师函，查她转账流水。
她以为我是吃醋，直到男大学生拿着她最后的钱去赌博，才哭着回来求我。
```

## 12. 最终成稿检查清单

写完后按下面清单自检：

### 开篇

- [ ] 300 字内是否出现极端憋屈场面？
- [ ] 500 字内男主是否完成第一次强反击？
- [ ] 反派是否足够逆天，让读者天然站男主？

### 主角

- [ ] 男主是否不解释、不自证、不求爱？
- [ ] 男主是否掌握现实资源，而不是只会骂？
- [ ] 男主是否每次都让反派付出具体代价？

### 反派

- [ ] 女主/亲属是否持续高位幻觉？
- [ ] 绿茶是否先卖惨、后撕脸？
- [ ] 反派是否每次误判后都损失更多？

### 爽点

- [ ] 是否有当众打脸？
- [ ] 是否有冻结/断供/辞退/追回/报警/公告等现实惩罚？
- [ ] 是否有围观群众或下属补刀？
- [ ] 是否有反派内部互咬？

### 节奏

- [ ] 是否每个场景都有冲突升级？
- [ ] 是否避免大段背景说明？
- [ ] 是否每 300-600 字至少有一个新爽点或新压力？

### 结尾

- [ ] 是否拒绝复合？
- [ ] 是否不给反派体面？
- [ ] 是否让反派自食恶果？
- [ ] 是否让男主抽身享受新生活？

## 13. 一句话总诀

**先让读者替男主憋屈到冒火，再让男主用最短、最狠、最现实的方式，一层层夺回尊严、钱、权、身份和人生；反派越嘴硬，后果越惨；她们不是被教育，而是被现实碾碎。**
