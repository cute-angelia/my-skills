# 爽文输入模板

这个模板给 `v-novel-write-shuangwen` 配套用。
用途不是让用户每次都填满，而是当素材散、信息不够、想快速把需求喂给 agent 时，直接复制一份填写。

## 极简版

适合你已经有想法，只想快速开写。

```text
题材：
要写什么：开篇 / 第X章 / 续写 / 改写 / 短篇完整故事
字数：
主角：
反派：
核心矛盾：
开局场面：
主角底牌：
反派加码：
结尾钩子：
原文/梗概：
```

## 标准版

适合想把一章需求喂得更稳一点。

```text
你按番茄爽文口感，直接给我写正文，不要分析。

题材：
【都市 / 家庭 / 重生 / 复仇 / 修仙 / 职场 / 商业 / 悬疑 / 其他】

需要写的内容：
【开篇 / 第几章 / 续写 / 改写 / 短篇完整故事】

字数要求：
【比如 2000 字 / 3000 字 / 一章】

主角设定：
【姓名、年龄、身份、当前困境】

反派设定：
【姓名、身份、压迫主角的手段】

核心矛盾：
【一句话说清谁害谁、为什么害、主角要拿回什么】

开局场面：
【第一幕发生在哪里，谁正在逼主角做什么】

主角底牌：
【主角手里有什么证据、能力、关系、信息差】

反派加码：
【反派下一步怎么逼主角、羞辱主角、扩大局面】

本章结尾钩子：
【结尾要抛出什么危机 / 反转 / 下一步】

原文或剧情梗概：
【直接粘贴】
```

## 改写版

适合你已经有一段原稿，但写得不够爽、不够顺、不够像番茄连载。

```text
把下面这段改成番茄爽文口感，直接输出正文，不要分析。
要求：
1. 保留人物、事件、矛盾、设定、剧情走向
2. 不乱加新设定
3. 增强冲突、节奏、压迫感、反派加码和结尾钩子
4. 强去 AI 味，不要总结式，不要说明书式
5. 主角可以忍，但不能蠢；反派要有利益和算计

题材：
本段作用：
希望强化的点：
不能改的点：
原文：
【粘贴原文】
```

## 续写版

适合上一章已经写完，下一章要接着往下推。

```text
按番茄爽文节奏续写下一章，直接给正文，不要分析。

已发生剧情：
【上一章到目前为止发生了什么】

当前卡点：
【现在主角卡在什么局面里】

本章目标：
【本章至少要推进哪 2~3 个环节】

必须保留：
【设定 / 人物关系 / 伏笔 / 不能改动的信息】

反派本章怎么加码：
【写清楚】

主角本章底牌：
【证据 / 关系 / 信息差 / 能力】

结尾钩子：
【下一章要追读的点】
```

## 短篇完整故事版

适合一次性写完一个完整爽文故事。

```text
写一个番茄爽文短篇，直接出正文，不要分析。

题材：
字数：
主角：
反派：
故事核心钩子：
主角要拿回什么：
反派怎么压主角：
主角底牌是什么：
希望的结局清算：
是否带反转：
```

## 使用提醒

1. 不需要每次把模板填满，能写清核心矛盾就先写。
2. 如果已有原文，优先直接贴原文，别只抽象描述。
3. 如果你特别在意哪些不能改，单独列一个“不能改的点”。
4. 如果你已经想好结尾钩子，明确写出来，正文会更稳。
5. 如果是长篇连载，最好补一句“这是第几章、前情到哪”。
