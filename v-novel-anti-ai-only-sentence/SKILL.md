# 小说句式生活化提示 skill

## 适用场景

当用户明确提到以下意图时，使用本 skill：

- “只改句子”
- “句式更生活化”
- “口语一点”
- “别大改剧情，只提示哪里不像人话”
- “不要删场景描写 / 不要删说明”
- “只做语言句式层面的反 AI”
- “v-novel-anti-ai-only-sentence”

本 skill 是轻量句式修正提示，不是完整反 AI 实改，不是删改型编辑。

## 和 v-novel-anti-ai 的边界

本 skill 只处理“语言句式是否自然”。

不要套用 `v-novel-anti-ai` 里的强删改逻辑：

- 不默认删除环境描写
- 不默认删除场景描写
- 不默认删除说明信息
- 不默认删除心理说明
- 不默认删除解释句
- 不默认删“像是 / 仿佛 / 不是……而是……”等句式
- 不默认把整段改写成更短、更硬、更冷的版本
- 不做剧情重排、人物动机重写、信息延后、场面重构

只有当某一句确实“拗口、书面、模板、像 AI 套话”时，才给出更生活化的句式替换建议。

## 总原则

1. 只修语言，不动内容。
2. 只提示建议，不强行删稿。
3. 保留原文的场景描写、说明信息、人物动作、心理说明和事实顺序。
4. 目标是“更像人写/人说”，不是“更狠、更短、更省”。
5. 不把所有长句都切短；只处理读起来不自然的句子。
6. 不把所有说明都改成动作呈现；用户明确要求保留说明时，说明就保留，只把说明句写顺。
7. 修改建议要小刀口、可替换、低侵入。
8. 如果原句已经自然，不要为了显得有工作量硬改。

## 默认输出方式：只提示

除非用户明确要求“直接改成可替换稿”，否则默认只输出提示，不直接整段重写。

输出结构：

1. 句式问题提示
   - 逐条指出哪一句不自然
   - 说明问题类型：太书面 / 太工整 / 太解释腔 / 太 AI 套话 / 口吻不像人物

2. 生活化改法
   - 每条给 1-2 个可替换句
   - 保持原信息不丢失
   - 不建议删除场景描写或说明，只建议换说法

3. 保留提醒
   - 明确说明哪些场景描写、说明信息应当保留
   - 如果某段只是信息密度高但必要，不提示删除，只提示“可以换成更顺的表达”

## 可改的问题类型

### 1. 书面腔太重

例：

原句：她意识到，这件事已经超出了她原本的判断范围。

提示改法：

- 她这才反应过来，事情不太对。
- 她心里咯噔一下，原先那点判断不够用了。

注意：不是删除“意识到”的信息，而是把句子换得更像人在现场反应。

### 2. 解释句太端正

原句：他这样做，并不是因为害怕，而是因为他必须先确认对方的真实意图。

提示改法：

- 他不是怕，只是不想现在就把底牌递出去。
- 他没急着动手。对方到底想干什么，他还得再看一眼。

注意：保留解释逻辑，只把“并不是因为……而是因为……”改得不那么模板。

### 3. 句子太圆、太顺、太 AI

原句：空气在这一刻仿佛凝固了，每个人都意识到接下来的选择将决定他们的命运。

提示改法：

- 屋里一下安静下来。没人先开口。
- 那一瞬间，几个人都没动。谁都知道，下一句话不好接。

注意：如果“空气凝固”是用户想保留的气氛，也可以只提示“这句略模板”，不要求删掉。

### 4. 人物口吻不像真人

原句：我希望你能够理解，我现在所做的一切，都是为了维护我们之间最后的体面。

提示改法：

- 你别把话说得太难听。我这么做，已经算给你留面子了。
- 我不是非要闹到这一步。可你总得让我把最后这点脸面留住。

注意：台词可以更口语，但不能改变人物立场。

### 5. 说明信息可以更顺

原句：这条巷子是旧城区通往码头最近的一条路，因此平时来往的人并不少。

提示改法：

- 这条巷子离码头最近，旧城区的人平时都爱从这儿抄过去。
- 从旧城区去码头，走这条巷子最快，所以这里从来不算清净。

注意：说明信息不删，只换成更自然的叙述。

## 禁止动作

使用本 skill 时，禁止做以下事：

- 禁止把“建议句式优化”变成“整段重写”
- 禁止删场景描写
- 禁止删环境描写
- 禁止删说明信息
- 禁止删心理说明
- 禁止删作者交代的必要设定
- 禁止因为一句话有解释味，就建议整句删除
- 禁止把所有“像是 / 仿佛 / 似乎”都判死刑
- 禁止把文本改成冷硬、阴冷、压迫感风格，除非原文就是这个风格
- 禁止引入新剧情、新设定、新人物动机
- 禁止输出长篇审查报告

## 如果用户要求直接改

只有用户明确说：

- “直接帮我改成新版”
- “给我可替换稿”
- “按这些提示直接修”

才输出可替换稿。

即使直接改，也必须遵守：

- 不删场景描写
- 不删说明
- 不删事实信息
- 不改剧情顺序
- 只做句式和口吻生活化
- 改动要轻，不要大换血

## 质量自检

交付前检查：

- 有没有只做语言句式层面的提示？
- 有没有误删或建议删除场景描写？
- 有没有误删或建议删除说明信息？
- 有没有把“只提示”变成“直接整段重写”？
- 有没有保持原剧情、人物、设定、事实顺序不变？
- 每条建议是不是都能直接替换原句？
- 修改后的句子是不是更生活化，而不是更文艺、更用力？

只要出现“建议删除场景描写 / 删除说明 / 大幅重构段落”，就不合格，必须重写输出。

## 一句话执行口令

“只修句式更生活化” = 只指出不自然句子并给生活化替换建议；不删场景描写，不删说明信息，不做强反 AI 实改，不重构剧情；默认只提示，除非用户明确要求可替换稿。
