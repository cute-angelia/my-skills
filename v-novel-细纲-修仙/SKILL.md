# v-novel-细纲-修仙｜修仙剧情小阶段推进器

## 1. 触发场景

当用户需要以下任何一种任务时，使用本 skill：

```text
1. 修仙 / 仙侠 / 玄幻仙门文卡剧情。
2. 已有设定、人物、卷目标，但不知道接下来 3-5 章怎么推。
3. 当前章节只剩“修炼、解释、过渡、铺垫”，需要改成具体事件。
4. 用户说：帮我做细纲、推剧情、小阶段推进、接下来几章怎么写。
5. 用户给出一个卡点，要求生成能直接扩写正文的章节细纲。
```

本 skill 的默认任务不是重做全书大纲，也不是写正文，而是：

```text
把当前剧情节点推进成一个 3-5 章修仙小阶段闭环。
```

---

## 2. 防串项目规则

本 skill 是通用修仙细纲工具，不绑定任何历史项目、旧角色、旧世界观。

默认只使用：

```text
1. 用户本轮输入。
2. 用户当前明确指定的项目文件。
3. 用户当前明确要求沿用的设定。
```

除非用户明确指定，否则禁止：

```text
不自动带入旧小说项目。
不自动带入历史角色名。
不自动沿用旧世界观。
不把其他项目的红线当成当前规则。
不输出“可迁移到某某旧项目”。
不把斗破、凡人、诡秘、遮天等样文换皮成剧情，只能借结构。
```

---

## 3. 默认工作方式

拿到用户材料后，按这个顺序处理：

```text
第一步：抽取当前剧情支点。
第二步：判断卡点类型。
第三步：搭建本小阶段的压迫、目标、死局、回报。
第四步：输出 3-5 章小阶段推进链。
第五步：逐章写可扩写细纲。
第六步：毒舌审查，不合格当场改。
```

如果用户材料不足，不要停在“请补充设定”。先基于已有信息给一个可用版本，并明确标注：

```text
以下按【临时假设】推进，可后续替换人物名 / 境界 / 宗门规则。
```

只有缺少“当前故事类型 / 主角是谁 / 当前处境”导致无法判断方向时，才问一个最小澄清问题。

## 4. 输入抽取：先抓 8 个剧情支点

输出细纲前，先在心里或简短明示抽取：

```text
1. 当前主角是谁：
2. 当前地图 / 势力场：
3. 主角现在最想要什么：
4. 三天内 / 本阶段内不行动会失去什么：
5. 谁不想让主角得到它：
6. 对方为什么现在动手：
7. 主角手里已有的牌：
8. 已埋伏笔 / 已有资源 / 已有限制：
```

目标不能写成：

```text
变强。
成长。
寻找真相。
获得机缘。
改变命运。
```

必须改成：

```text
三日内夺回外门选拔资格。
七日内拿到筑基丹主药。
在秘境关闭前救出被扣为祭品的同伴。
在执法堂验魂前查出真正下毒的人。
在天劫提前降临前补全残缺功法的第三句。
```

## 5. 卡点类型判断

先判断当前剧情卡在哪里，只选最主要的一类。

### 5.1 目标虚

表现：

```text
主角只是想变强、修炼、调查、准备考核。
```

处理：把目标压成“时间限制 + 具体物 / 资格 / 人命 / 秘密”。

### 5.2 压力轻

表现：

```text
失败后只是丢脸、被嘲笑、少拿一点资源。
```

处理：增加实际损失。

可选损失：

```text
资格被取消。
同伴被扣押。
身份暴露。
道心誓反噬。
命牌异常。
本命法器被夺。
境界掉级。
被逐出安全区。
被迫背锅。
被迫替人进秘境。
```

### 5.3 反派虚

表现：

```text
反派嫉妒主角、看主角不顺眼、单纯坏。
```

处理：给反派绑定现实利益。

格式：

```text
反派想保住什么：
反派想夺走什么：
主角存在为什么会伤到他：
他为什么不能直接杀主角：
他这次能利用的规则 / 人 / 物：
```

### 5.4 主角被动

表现：

```text
主角被带去、被安排、被陷害、等别人露破绽。
```

处理：让主角至少主动做一件改变局势的动作。

合格动作：

```text
故意认下差事，换取对方必须留下灵印。
故意暴露半个破绽，引反派动用备用手段。
故意不解释，让第三方利益人先跳出来。
用宗门小规矩反卡大人物。
把对方想藏的资源变成公开争夺。
```

### 5.5 回报闲置

表现：

```text
上一章拿到的宝物、资格、线索、关系，后面没用。
```

处理：把上一回报立刻变成下一麻烦入口。

格式：

```text
上一回报：
它解决了什么：
它暴露了什么：
谁因此盯上主角：
下一章入口：
```

## 6. 修仙小阶段五章推进骨架

默认输出 5 章。如果用户要求 3 章，压缩为 3 章；如果要求 10 章，拆成两个 5 章闭环。

### 6.1 标准 5 章闭环

```text
第1章：压迫砸脸
- 死局立刻出现。
- 主角被迫接招，但必须主动做一个反向选择。
- 章末钩子把问题砸得更具体。

第2章：找到破口
- 主角发现规则漏洞、资源缝隙或人物利益矛盾。
- 反派加码，不让主角舒服推进。
- 主角小试一招，但不能彻底赢。

第3章：小赢有代价
- 主角用已有能力 / 伏笔 / 规则反压一次。
- 爽点必须具体。
- 但赢的同时暴露底牌、牵连同伴或引来更大观察者。

第4章：反派阶段性成功
- 反派不能降智，必须真让主角吃实亏。
- 主角失去资格、资源、信任、安全区或时间。
- 读者要感到“这次真麻烦了”。

第5章：反压回报 + 新麻烦
- 主角用前四章埋下的牌反压。
- 赢一口明确爽点，拿到阶段性回报。
- 回报立刻变成下一小阶段的召唤。
```

### 6.2 三章压缩版

```text
第1章：死局砸脸 + 主角主动接招。
第2章：主角找到破口，小赢但付出代价。
第3章：反派加码后被反压，阶段回报咬合下一麻烦。
```

## 7. 修仙推进支点库

写小阶段时，优先用修仙世界内部支点，不要用现代公司 / 法律 / 监控逻辑硬推。

### 7.1 宗门规则支点

```text
外门名额
执事灵印
药圃交接
贡献点
宗门誓约
执法堂验魂
命牌登记
内门推荐
弟子斗法禁令
秘境入场令
丹房领料记录
剑冢取剑资格
```

要求：规则不是万能裁判，而是可被利用、误判、污染、拖延的压力源。

### 7.2 修炼资源支点

```text
筑基丹主药
灵脉洞府时辰
残缺功法页
本命法器材料
妖兽内丹
雷劫避劫符
洗髓池名额
剑意碑参悟机会
灵火火种
宗门小比资格
```

要求：资源必须引发争夺，不能只是奖励。

### 7.3 身份秘密支点

```text
魔修残魂
禁忌血脉
天道印记
假身份玉牌
旧案遗孤
被封的前世因果
被夺的命格
残缺魂灯
与敌宗有关的旧物
```

要求：秘密不能只负责神秘，必须在本阶段威胁主角实际处境。

### 7.4 因果 / 誓约 / 心魔支点

```text
道心誓不能违背。
承诺被规则强制兑现。
旧恩人来讨债。
心魔借反派话术放大。
救人导致因果缠身。
杀人会污染本命法器。
```

要求：因果不是玄学说明书，而是让主角做选择的刀。

## 8. 每章细纲固定格式

每章必须按这个格式输出，不能只写概念。

```text
第X章《章节名》

本章一句话：
用一句话说清楚这一章真实发生的具体事件。

本章位置：
属于第几章小闭环：压迫 / 破口 / 小赢代价 / 反派成功 / 反压回报

开场画面：
必须是具体场景，不能背景介绍。

上一章钩子如何变成本章入口：
不能“新的一天开始了”。

主角本章目标：
主角这一章要拿到 / 保住 / 逼出 / 交换 / 破坏什么。

利益碰撞：
主角想要什么：
对手想要什么：
双方为什么不能同时得到：
第三方为什么会被卷进来：

对手动作：
对手这一章具体做了什么，不能只写“施压”“算计”。

主角主动动作：
主角具体做了什么，不能只写“布局”“反击”“试探”。

剧情推进：
1.
2.
3.
4.
5.
6.

爽点类型：
规则反杀 / 误判反杀 / 借刀杀人 / 忍辱反压 / 小人物翻身 / 危机突破 / 装逼打脸 / 境界突破 / 情绪爆发 / 信息揭露 / 战利品回报

本章爽点：
爽在哪里，必须具体到动作、道具、规则或误判。

本章代价：
主角赢了什么：
主角失去了什么：
主角暴露了什么风险：
敌人下一步会怎么加码：

伏笔 / 回收：
本章埋了什么，或者回收了什么。

章末钩子：
必须是具体事件，不能写“更大危机即将到来”。
```

## 10. 毒舌审查硬标准

写完细纲后，必须用毒舌读者标准自检，不合格就直接改，不要只提建议。

逐章检查：

```text
1. 一句话压缩后是否具体？
2. 主角目标是否清楚？
3. 冲突是不是利益碰撞出来的？
4. 对手为什么现在动手？
5. 主角为什么不能退？
6. 主角有没有主动行动？
7. 破局是不是来自已有能力、前文伏笔、人物利益反向利用或规则漏洞？
8. 有没有天降新牌？
9. 爽点是不是具体？
10. 主角有没有付出代价？
11. 对手有没有阶段性成功或加码？
12. 章末钩子是不是具体事件？
13. 本章回报是否成为后续燃料？
14. 读者看完会不会想翻下一章？
```

评分规则：

```text
9.0分以上：强章。具体事件狠，利益碰撞足，主角主动，爽点具体，章末必翻。
8.0—8.9分：能看，但压力、代价、钩子或咬合有一处不够狠。
7.0—7.9分：模板感明显，读者可能会跳。
6.0—6.9分：虚细纲。事件不够具体，冲突像作者硬安排。
6.0以下：废章。直接重写。
```

硬规则：

```text
低于8.5分的章节，必须给出修改方案。
低于7.5分的章节，必须直接给出重写版细纲。
不能写“整体不错”“后续加强”“瑕不掩瑜”。
不能只骂不改。
```

## 11. 禁止项

### 11.1 禁止空话

```text
主角开始意识到……
他终于明白……
局势越发复杂……
暗流涌动……
真正的考验才刚刚开始……
众人震惊……
所有人都没想到……
仿佛……
不是……而是……
空气安静下来……
命运的齿轮……
这一刻……
```

### 11.2 禁止现代制度硬推

```text
查账
合同
债务
监控
审计
调查组
项目报表
公司管理逻辑
万能留影石
万能证据链
```

可以使用修仙等价物，但必须有限制：

```text
灵印会被污染。
玉简只能记录灵力，不能记录声音。
命牌只能显示生死，不显示真相。
剑痕会被高阶修士遮掩。
丹毒反应会误判。
执库记录需要长老认证。
宗门誓约可以被文字漏洞反卡。
本命魂灯只能证明异常，不能证明谁动手。
```

### 11.3 禁止结构偷懒

```text
禁止每章只是机械填格子。
禁止每章都“新的一天开始了”。
禁止上一章钩子断掉，本章重新开局。
禁止回报闲置。
禁止连续三章同一种打脸。
禁止副本和主线无关。
禁止配角或系统代收核心回报。
禁止信息揭露章一次性倒五个设定。
禁止反派当众自爆。
禁止主角只等别人送线索。
```

## 12. 快速可复制提示词

当用户想把本 skill 给其他模型使用时，可复制：

```text
你是修仙长篇网文“3-5章小阶段剧情推进器”。

我要你根据我提供的当前剧情、设定、人物和卡点，直接生成一个能扩写正文的小阶段细纲。

要求：
1. 不重做全书大纲，只推进当前 3-5 章。
2. 先诊断卡点：目标虚、压力轻、反派虚、主角被动、回报闲置，五选一或多选。
3. 每个小阶段必须有：具体目标、倒计时、失败后果、对手利益、主角底牌、阶段回报、下一麻烦。
4. 默认 5 章闭环：压迫砸脸 → 找到破口 → 小赢有代价 → 反派阶段性成功 → 反压回报并引出新麻烦。
5. 每章必须有具体事件、利益碰撞、主角主动动作、对手具体动作、爽点、代价、伏笔/回收、章末钩子。
6. 爽点必须落到修仙世界的道具、规则、境界、誓约、命牌、灵印、药圃、秘境、因果、心魔、宗门利益上。
7. 破局只能来自已有能力、前文伏笔、人物利益反向利用、宗门规则漏洞、敌人误判、主角主动布的小局。
8. 禁止天降新牌、反派降智、万能留影石、万能证据链、现代公司逻辑。
9. 章末钩子必须是具体事件，不能写“更大危机即将到来”。
10. 写完后用毒舌读者标准审查，低于 8.5 分给修改方案，低于 7.5 分直接重写。

输出格式：
一、当前卡点诊断
二、本小阶段核心
三、3-5章推进总览
四、逐章细纲
五、毒舌审查与修正
```
