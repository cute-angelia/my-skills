# v-novel-大纲排雷清单

这个 skill 解决一件事：
在写正文之前，先把“初始大纲 / 简版大纲 / 番茄短爽文骨架”过一遍排雷清单，让剧情从角色伤口和利益冲突里长出来，而不是靠误会、巧合、全场震惊和作者解释硬推。

## 何时触发

用户出现以下意图时触发本 skill：

- “帮我做一个短爽文初大纲”
- “番茄短爽文简版大纲”
- “检查这个大纲有没有问题”
- “给这个爽文大纲排雷”
- “完善大纲”
- “先别写正文，先看大纲”
- “这个短剧/爽文设定能不能写”
- “把这个梗做成可写的大纲”

适用范围：

- 番茄短爽文
- 家庭打脸 / 偏心清算 / 火葬场 / 情感清算类短篇
- 短剧感爽文的大纲排雷
- 开篇前的剧情骨架检查
- 已有梗概的补强与删水

不适用范围：

- 用户明确要求直接写正文：优先切到 `v-novel-write-shuangwen`
- 用户明确要求多角色长篇审查：优先切到 `v-novel-multi-role-review`
- 用户明确要求拆样文机制：优先切到 `v-novel-chaiwen`
- 用户明确要求新小说选题孵化：优先切到 `v-novel-新小说开坑总控`

## 默认工作方式

不要把本 skill 输出成空泛写作课。要么直接给一版可执行初大纲，要么对用户已有大纲做“排雷 + 修正后版本”。

默认步骤：

1. 先判断用户要的是“从 0 生成”还是“审查已有大纲”。
2. 把大纲拆成：核心伤口、核心利益、主角损失、反派利益、关键冲突、时间线、回报节点。
3. 按七道关卡逐项排雷。
4. 删掉无利益变化、无人物选择、无真实损失的水剧情。
5. 把强行误会、强行巧合改成利益误判、信息遮掩、恐惧驱动或私心选择。
6. 输出能直接进入细纲/正文阶段的大纲。

分析要短，修改要实。用户没有要求长报告时，不要大段解释理论。

## 七道排雷关卡

### 一、剧情关：必须有利益驱动

硬规则：

- 每个剧情节点都必须有利益驱动。
- 每场冲突必须有人真正失去东西。
- 能删掉且不影响主线的剧情，就是水。
- 禁止“为了剧情而剧情”。
- 禁止强行误会。
- 禁止强行巧合。

检查问题：

- 这一场里谁想得到什么？
- 谁害怕失去什么？
- 主角如果不行动，会立刻丢掉什么？
- 反派如果不压主角，会损失什么？
- 这一场结束后，局势有没有变化？

合格变化至少落到一个具体项：

- 钱
- 脸面
- 资格
- 名声
- 房子 / 资源 / 名额
- 亲密关系
- 选择权
- 话语权
- 靠山
- 证据 / 把柄

### 二、角色关：每个人都要有伤口

核心角色必须至少具备其中几项：

- 恐惧
- 愧疚
- 执念
- 后遗症
- 脆弱点

禁止：

- 完美主角
- 纯坏反派
- 工具人配角
- 只负责震惊、递证据、解释设定的配角

执行要求：

- 主角的行动要从伤口、损失和底线里长出来。
- 反派的压迫要从利益和自我合理化里长出来。
- 配角要有自己的算盘：站队、避险、保饭碗、抢功劳、甩锅、求安全。

角色补强模板：

```text
【角色】害怕【失去物】，因为过去有【伤口/后遗症】；现在他/她执着于【目标】，所以在【冲突场景】里做出【选择】，并导致【代价/局势变化】。
```

### 三、感情线关：火葬场不是虐，是迟来的理解

硬规则：

- 火葬场核心不是虐，是迟来的理解。
- 感情必须来自相处，不是设定。
- 前期越真实，后期越扎心。
- 禁止轻易原谅。
- 禁止工业糖精式深情。

检查问题：

- 两个人的感情是否有具体共同经历？
- 被伤害的一方到底失去了什么？
- 迟来理解发生时，对方到底看懂了哪件具体事？
- 原谅是否需要代价、行动和时间？

禁止把“他其实很爱她”“她终于明白”当成情感推进。必须落到具体行动、错过、补偿失败、代价承担。

### 四、反派关：反派必须认为自己是对的

硬规则：

- 反派必须认为自己是对的。
- 反派必须赢过。
- 反派必须有自己的利益逻辑。
- 禁止降智反派。
- 禁止纯恶模板。

反派设计最少补齐：

- 他想保住什么？
- 他想抢走什么？
- 他为什么觉得主角活该？
- 他过去赢过主角哪一次？
- 他这次误判了什么？

更好的反派失控：

- 越权
- 改口
- 灭口
- 转移责任
- 私下施压
- 逼第三方背书
- 为遮小错暴露大利益链

不要让反派只会吼、只会嘴贱、只会送证据。

### 五、时间线关：开写前必须锁定

开写前必须锁：

- 年龄
- 时间跨度
- 学历
- 资历
- 关键事件顺序

禁止边写边补时间线。

最低要求：

```text
过去伤口发生在【时间点】；
主角因此形成【恐惧/执念/后遗症】；
当前冲突发生在【现在时间点】；
反派利用【旧事/关系/资源】压主角；
主角通过【证据/选择/行动】改变局势。
```

若时间线不清，先补时间线，不要直接写正文。

### 六、短剧感排雷：少套路，多现场

少用或默认避开：

- 全场震惊
- 全球首富
- 黑客萌宝
- 跪雨
- 一巴掌打脸
- 只靠身份反转碾压
- 只靠围观者统一倒戈

多写：

- 安静戏
- 日常感
- 微情绪
- 呼吸感
- 具体动作
- 具体损失
- 具体选择

注意：
“安静戏 / 日常感 / 微情绪”不能变成空镜头。它们必须暴露人物关系、压力、伤口或利益变化。

### 七、正文写法关：禁说明书，保动作推进

虽然本 skill 主要处理大纲，但大纲里也要提前排掉正文会变坏的写法。

禁止倾向：

- 总结式
- 说明书式
- AI 排比
- 金句轰炸
- 作者点评
- 旁白替人物做判断
- 大段解释人物为什么痛苦、为什么愤怒、为什么醒悟

需要预留的正文抓手：

- 动作推进
- 微反应
- 停顿
- 沉默
- 细节情绪
- 物件
- 对话漏洞
- 选择代价

大纲节点不要写成：

```text
女主很痛苦，男主终于意识到自己错了，所有人都被真相震惊。
```

要改成：

```text
女主把旧围巾放回纸箱，没骂人，只问男主还记不记得那年冬天是谁替他签的手术同意书；男主第一次接不上话，母亲急着打断，反而说漏当年转院单是她藏的。
```

## 与其他本地小说 skill 的边界

- 本 skill 是“初大纲排雷 / 简版大纲补强”，不是正文直出。
- 写正文交给 `v-novel-write-shuangwen`。
- `v-novel-write-shuangwen` 如果拿到的是大纲、细纲、剧情梗概，且用户没有明确要求立刻正文，可以先引用本 skill 做一轮轻量排雷，再进入正文直出。
- 多角色严审交给 `v-novel-multi-role-review`。
- 长篇结构拆解交给 `v-novel-chaiwen`。
- 新项目从选题到开坑孵化交给 `v-novel-新小说开坑总控`。
- 本 skill 可以作为这些 skill 之前的轻量前置关卡。

## 最终自检

交付前必须确认：

- [ ] 每个关键剧情节点都有利益驱动。
- [ ] 至少一场冲突有人真实失去东西。
- [ ] 主角不是完美纸片人，有伤口和脆弱点。
- [ ] 反派不是纯坏模板，有自认为正确的利益逻辑。
- [ ] 配角不是只负责震惊或递工具。
- [ ] 感情线来自相处、代价和迟来的理解，不靠设定硬说。
- [ ] 年龄、时间跨度、学历/资历和关键事件顺序没有明显冲突。
- [ ] 删掉了全场震惊、全球首富、黑客萌宝、跪雨、一巴掌打脸等廉价短剧感套路。
- [ ] 大纲为正文预留了动作、微反应、停顿、沉默和细节情绪，而不是总结式说明。
- [ ] 最终版本能直接进入细纲或正文阶段。
