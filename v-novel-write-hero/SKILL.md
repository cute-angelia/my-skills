# v-novel-write-hero

## 这个 skill 解决什么问题

当用户要写男频快节奏连载、设计章节、续写正文、拆/修弧线、安排卷级衔接、检查章节是否“飘”、或者要求“按英雄之旅/嵌套齿轮/斗破苍穹/诡秘之主那种结构感”处理网文时，使用本 skill。

核心原则：

英雄之旅不是每章填一遍的模板，而是在不同尺度上自我复制的嵌套齿轮。大旅程套中旅程，中旅程套小旅程，环环咬合。

适用场景：男频快节奏连载，默认 2000-3000 字/章。

## 防串项目规则

本 skill 是通用结构技能，不绑定任何单本小说、历史项目、旧角色或旧世界观。

默认只使用：
1. 用户本轮输入
2. 用户当前明确指定的项目文件
3. 用户当前明确要求沿用的设定

除非用户在当前任务中明确指定某本书、某个项目、某个角色或旧稿，否则：
- 不自动带入历史记忆里的小说项目、人物、设定、章节桥段
- 不把其他项目的创作规范 / 风格契约 / 红线文档当成当前写作规则
- 不输出“可迁移到某某项目 / 某某角色”这类历史映射
- 不把斗破苍穹、诡秘之主的例子当作可直接换皮的设定，只把它们作为结构示范

## 触发条件

用户出现以下意图时，触发本 skill：

- “按英雄之旅写一章 / 设计一卷 / 设计弧线”
- “这个章节怎么嵌套”
- “让章节更有齿轮感 / 嵌套感 / 推进感”
- “写男频快节奏连载章节”
- “做升级流 / 副本流 / 调查流 / 复仇流结构”
- “卷和卷怎么衔接”
- “这个大纲是否水 / 飘 / 断档 / 没咬合”
- “像斗破 / 诡秘那样分析结构，不是模仿设定”
- “检查每章爽点、钩子、回报、主线推进”

不适用：
- 只做语言去 AI 味、不需要结构治理时，优先用反 AI / humanizer 类 skill
- 只做拆文样本分析时，优先用 v-novel-chaiwen
- 只做番茄爽文正文直出时，可与 v-novel-write-shuangwen 联用，但本 skill 负责结构齿轮，正文口感由爽文 skill 负责

## 输出原则

根据用户任务选择输出形态：

1. 写正文：直接给正文，不长篇解释。内部完成五层定位、模式选择和咬合检查。
2. 做章节/弧线/卷纲：输出“阶段位置 + 嵌套模式 + 章节节拍 + 回报咬合 + 下一钩子”。
3. 做审查：指出卡点属于哪种齿轮故障，并给可替换方案。
4. 做续写：先识别上一章钩子，把上一章钩子直接变成本章入口，禁止“新的一天开始了”式断开。

## 一、核心认知：英雄之旅是嵌套齿轮，不是填空模板

### 1.1 两种用法

新手用法：拿到模板 → 每章填六个格子 → 写出来像流水线产品。

大神用法：理解英雄之旅是一个自相似结构 → 在场景 / 章 / 弧 / 卷 / 全书五个尺度上同时运行 → 小旅程的回报恰好是大旅程的燃料 → 环环咬合，齿轮联动。

《斗破苍穹》和《诡秘之主》的章节单独拆开看，每一章都能找到英雄之旅的影子，但不是“填”出来的，是嵌套出来的。

### 1.2 五层旅程

```text
全书旅程（200章+）  ─  废柴→巅峰，一个完整的神话弧线
  └─ 卷旅程（40-50章）  ─  一个完整舞台的进入→征服→离开
       └─ 弧线旅程（5-10章）  ─  一个完整事件的起→承→转→合
            └─ 章旅程（1章）  ─  一个独立消费单元，有考验有回报
                 └─ 场景旅程（300-800字）  ─  一个微型节拍，压力→释放
```

每往下一层，结构是上一层结构的分形复制。不是内容复制，是节奏模式复制。

### 1.3 嵌套铁律

1. 上层提供方向，下层独立消费。
   - 卷级旅程决定“这一卷要打到哪个 Boss”。
   - 但每一章读者可以不记得卷目标，只享受本章。

2. 下层回报是上层燃料。
   - 一章的微型回报（拿到道具）累积成弧线资源。
   - 弧线回报（战力跃升）成为卷旅程跨越门槛的资格。

3. 同一时刻，主角身处所有五层旅程中。
   - 写一章时，必须知道这一章在弧线、卷、全书旅程中处于哪个阶段。


## 一点五、剧情小阶段推进法：把“场景旅程”写实

当用户问“下一小段怎么推”“这一章中间怎么填”“大纲有了但正文卡住”时，不要只回答宏观英雄之旅，必须把当前章节拆成 1-3 个“剧情小阶段”。

小阶段定义：

- 不是一整章
- 不是一个大事件
- 通常是 300-800 字的场景旅程
- 必须完成一次压力变化、利益变化或信息变化
- 结尾要给小回报或新钩子

每个小阶段按六步推进：

1. 钩子入场：直接从压力、异常、损失、挑衅、危险、资格被夺、资源被断处切入。
2. 三方站位：主角方、阻拦方、第三方；第三方必须有自己的算盘，不只负责震惊。
3. 误判与压迫：反派为什么以为自己稳赢；主角暂时忍，是在观察、记账、套话、借势。
4. 反派加码：让主角损失扩大，让第三方站错队，让规则或资源进一步压下来。
5. 主角破局：用具体物件、规则、证据、实力、权限、旧账、话术漏洞或现场行动反制。
6. 回报与钩子：反派吃亏 / 第三方动摇 / 主角拿到筹码 / 上一层势力露头。

写作判断：

- 如果这个小阶段删掉后，章节主线不受影响，就是水。
- 如果小阶段只有氛围、赶路、解释设定，没有利益变化，就是空转。
- 如果主角只是在听别人解释，没有观察、选择、试探、借势或反打，就是被动。
- 如果反派只是吼，没有利益、误判、加码，就没有压迫。

小阶段最简公式：

```text
主角要拿到【目标】，反派为了【利益】阻拦，第三方因为【算盘】暂时站错边；反派加码让主角损失扩大；主角抓住【漏洞/物件/规则/证据】反制，拿到【小回报】，同时引出【下一层麻烦】。
```

与英雄之旅嵌套关系：

- 小阶段 = 场景旅程的最小齿轮。
- 一章通常由 2-3 个小阶段组成。
- 小阶段回报必须喂给章级回报；章级回报必须喂给弧线回报。
- 不要为了填英雄之旅格子而写场景；要让每个小阶段自己咬合、自己转动。


### 小阶段变奏与防僵化规则

上面的六步是底层检查清单，不是正文明面顺序。

允许：

- 先给小回报，再揭开主角前面观察到了什么。
- 先让第三方加码，再让反派误判暴露。
- 主角破局只破一半，把更大的破局留给下一章。
- 同一场景把“三方站位”和“误判压迫”藏进对白、动作、流程变化里。
- 非打脸场景也使用小阶段：调查、潜伏、谈判、逃亡、修炼突破、情报交换、资源分配。

禁止：

- 每个小阶段都按同一顺序写成“被压 → 加码 → 反杀”。
- 每个反派都用同一种轻蔑、同一种嘴贱、同一种失控。
- 每个第三方都在同一节点倒戈。
- 每个回报都写成打脸。

### 第三方类型库

第三方不是背景板，也不是统一震惊机器。写小阶段时，至少确认第三方属于哪一类：

| 第三方类型 | 常见算盘 | 推进功能 |
|---|---|---|
| 规则方 | 怕担责、怕流程被追责、怕上级查旧账 | 临时改口、拖延、背书或拒绝背书 |
| 资源方 | 保钱、保丹药、保项目、保名额、保库存 | 决定谁拿到实际收益 |
| 舆论方 | 看风向、怕站错队、想蹭热度 | 放大羞辱或放大反转 |
| 潜在盟友 | 试探主角值不值得押注 | 递线索、暗中留门、关键时刻不补刀 |
| 上层势力 | 不愿下场，但怕底层失控 | 露出一只手，制造下一阶段钩子 |
| 信息持有者 | 有把柄、有旧账、有证据但不敢说 | 让主角套话、逼供、交换条件 |

### 真加码判定

反派加码不是声音变大，也不是骂得更狠。

真加码必须让局势至少发生一个变化：

- 主角损失扩大。
- 时间被压缩。
- 退路减少。
- 第三方被迫表态。
- 规则被锁死。
- 证据被夺、被毁、被污染。
- 上层势力开始介入。
- 主角要保的人被卷入。

如果加码之后主角的处境没有更难，只是反派多说了几句狠话，这是假加码，删或改。

### 破局伏笔要求

主角破局不能像凭空掏答案。

用于破局的物件、规则、证据、权限、旧账、话术漏洞，必须至少提前露过一次脸：

- 主角多看了一眼。
- 主角故意拖了一句话。
- 某个配角无意说漏。
- 流程里出现一个不合理细节。
- 反派为了加码主动留下破绽。
- 第三方因为自保没有把话说死。

读者可以不知道主角完整计划，但必须看见主角在观察、留证、诱导、记账或借势。

### 连续小阶段变奏

一章内连续 2-3 个小阶段时，不能重复同一种齿轮。

至少变一个：

- 压迫类型：羞辱 / 资源 / 规则 / 时间 / 人质 / 舆论 / 信息。
- 第三方类型：规则方 / 资源方 / 舆论方 / 潜在盟友 / 信息持有者。
- 主角动作：忍 / 套话 / 借势 / 反问 / 示弱 / 抢先行动 / 暗中留证。
- 回报类型：打脸 / 获利 / 关系转向 / 信息入手 / 权限提升 / 危机暂缓。
- 结尾钩子：新敌 / 新规则 / 新地图 / 旧账 / 更高层压力。

## 二、六大嵌套模式

六种模式不是互斥的。一部小说通常同时使用 3-4 种。

### 2.1 套娃嵌套 Matryoshka

定义：一个完整的小旅程，整体嵌在大旅程的某一个阶段内部。

结构示意：

```text
卷旅程：跨越门槛 → 考验+盟友+敌人 → 接近洞穴 → 磨难 → 回报
                              ↑
                    这一段“考验”内部，是一个完整的小旅程：
                    召唤（被挑衅）→ 考验（对抗）→ 磨难（险些落败）
                    → 回报（反杀+打脸）→ 新钩子（对方背后的人出现）
```

斗破苍穹实例：炼药师大赛嵌在迦南学院卷的“考验”阶段。

```text
迦南学院卷（大旅程）
  ├─ 跨越门槛：进入内院
  ├─ 考验阶段内部嵌套——炼药师大赛（完整小旅程）：
  │    ├─ 召唤：得知大赛消息，需要证明自己
  │    ├─ 考验：初赛淘汰、对手挑衅、药材受限
  │    ├─ 磨难：决赛被出云帝国炼药师压制
  │    ├─ 回报：反超夺冠 + 收服异火 + 声望暴涨
  │    └─ 新钩子：韩枫察觉异火气息
  ├─ 接近洞穴：韩枫势力浮现
  └─ 磨难+回报：大战韩枫，吞噬陨落心炎
```

使用场景：需要在长线积累中插入完整爽点闭环，防止读者在“考验期”流失。

智能体使用法则：
- 当一个大旅程的“考验”阶段超过 10 章时，必须在其中嵌入至少一个完整小旅程。
- 小旅程必须有独立召唤 → 磨难 → 回报闭环。
- 小旅程的回报必须推进大旅程，不能是纯支线。
- 小旅程结束后，主角回到大旅程时状态已变：战力 / 声望 / 信息至少一项提升。

### 2.2 分形自相似 Fractal Self-Similarity

定义：同一戏剧节奏模式在五个尺度上自我复制。

结构示意：

```text
全书：平凡世界→跨越门槛→考验积累→接近洞穴→磨难→复活→回归
  └─ 每卷：日常→小Boss→大Boss→突破→新地图
       └─ 每弧线：信息→调查→遭遇→危险→解决→新线索
            └─ 每章：钩子→目标→障碍→突破→回报→新钩子
                 └─ 每场景：平静→异常→紧张→释放
```

诡秘之主的核心节奏 DNA：调查 → 遭遇 → 危险 → 解决 → 新线索。

示例：
- 场景级：占卜发现线索 → 遭遇隐秘存在注视 → 险些失控 → 用扮演法稳定 → 获得序列配方线索。
- 章级：醒来困惑 → 发现笔记本密码 → 尝试理解世界 → 初步掌握仪式 → 决定加入值夜者。
- 弧线级：日常值夜者任务 → 调查连环凶案 → 发现因斯·赞格威尔 → 队长牺牲 → 获得封印物并离开廷根。

使用场景：悬疑 / 调查 / 克苏鲁类网文核心手法，让读者在任何尺度进入都能获得相同阅读快感。

智能体使用法则：
- 先确定核心节奏 DNA，例如“信息 → 行动 → 危险 → 突破 → 新信息”。
- 确保这个节奏在场景 / 章 / 弧线三个尺度上都可识别。
- 斗破的核心节奏 DNA 是“目标 → 压制 → 突破 → 打脸 → 新目标”。
- 禁止在不同尺度用不同节奏 DNA，否则读者会感到“不在状态”。

### 2.3 链式咬合 Chain Interlocking

定义：旅程 A 的回报直接转化为旅程 B 的召唤。A 的终点就是 B 的起点。

斗破苍穹实例：异火收服 → 炼药师大赛。

```text
旅程A：收服青莲地心火
  ├─ 召唤：从药老处得知异火位置
  ├─ 考验：穿越沙漠、对抗蛇人族
  ├─ 磨难：与美杜莎女王争夺异火
  ├─ 回报：吞噬青莲地心火，实力跃升
  └─ 新钩子：异火气息被炼药师公会察觉
          ↓  咬合点：A 的新钩子就是 B 的召唤
旅程B：参加炼药师大赛
  ├─ 召唤：炼药师公会因异火注意到主角，发出邀请
```

诡秘之主实例：廷根卷 → 贝克兰德卷。

```text
旅程A：廷根市
  └─ 回报：获得封印物、晋升、得知真实造物主存在
          ↓  咬合点：队长临终托付 + 封印物线索指向贝克兰德
旅程B：贝克兰德
  ├─ 召唤：以侦探身份进入贝克兰德，追查因斯·赞格威尔
```

使用场景：卷与卷、弧线与弧线之间的过渡。

智能体使用法则：
- 永远不要让上一个旅程的回报闲置，它必须成为下一个旅程的入场券。
- 写一个旅程结尾时，同时写下个旅程的开头句。
- 咬合点必须同时满足：
  1. 是前一个旅程的自然结果
  2. 引入新的冲突 / 信息 / 舞台
- 常见错误：旅程 A 结束后主角“休息了一段时间”再开始旅程 B。这会打断咬合。

### 2.4 主线-副本 Main Quest — Side Quest

定义：一个贯穿多卷的主旅程作为骨架，通过不断进入副旅程获取主旅程所需资源 / 信息 / 战力。

斗破苍穹实例：三年之约作为主旅程骨架。

```text
主旅程：三年之约复仇
  ├─ 副本1：魔兽山脉试炼 → 获得飞行斗技+战斗经验
  ├─ 副本2：塔戈尔沙漠 → 收服青莲地心火
  ├─ 副本3：炼药师大赛 → 获得炼药师身份+丹方
  ├─ 副本4：黑角域 → 收服陨落心炎
  └─ 回到主线：三年之约，上云岚宗
       └─ 打完发现新主线：云岚宗背后是魂殿
```

结构特征：
- 主旅程提供方向：读者知道最终要打谁。
- 副本提供即时爽点：每个副本有独立闭环。
- 每个副本结束时，主角离主旅程目标更近一步，读者能感知进度条。
- 副本之间通过链式咬合连接。

使用场景：长线复仇 / 争霸 / 升级流核心结构。

智能体使用法则：
- 主旅程必须在前期，最好前 10 章内埋下，让读者知道最终要打谁。
- 每个副本必须：
  1. 独立可消费
  2. 推主线进度
  3. 引入一个新信息 / 新势力
- 副本不能超过 5 个而不回主线，否则读者会忘记主目标。
- 常见错误：副本和主线无关，或副本太多导致主线失焦。

### 2.5 升级螺旋 Escalation Spiral

定义：同一个结构模式在不同层级上重复，但每次代价更大、对手更强、回报更高。不是简单换地图，而是每次循环都让主角本质发生质变。

诡秘之主实例：序列晋升螺旋。

```text
序列9→8
  模式：找配方 → 收材料 → 消化魔药 → 晋升
  代价：初步失控风险
  对手：普通非凡者
  回报：获得占卜能力

序列8→7
  模式：找配方 → 收材料 → 消化魔药 → 晋升
  代价：听到隐秘存在低语，险些失控
  对手：更高序列非凡者 + 隐秘影响
  回报：获得纸人替身能力

序列7→6
  模式：找配方 → 收材料 → 消化魔药 → 晋升
  代价：人格分裂风险，需要扮演不同身份
  对手：邪神教会与高序列非凡者
  回报：获得无面人能力
```

斗破苍穹实例：异火收服螺旋。

```text
青莲地心火：对抗蛇人族女王，代价是拼命，回报是大斗师
陨落心炎：对抗韩枫+黑角域势力，代价是重伤，回报是斗王
净莲妖火：中州级势力争夺，代价是半条命，回报是斗圣
```

使用场景：升级流 / 系统流核心驱动引擎。主角成长不是线性累积，而是螺旋上升。

智能体使用法则：
- 每次螺旋重复时，结构可以相同，但三个变量必须递增：对手量级、主角代价、回报规模。
- 读者期待螺旋重复，但突破方式必须不同：第一次战斗突破，第二次领悟突破，第三次吞噬突破。
- 螺旋之间必须有冷却段：展示新能力使用、旁人对新实力反应。
- 不能连续螺旋。
- 常见错误：只涨数值不变方式，变成“又升一级，没感觉了”。

### 2.6 多线收束 Multi-thread Convergence

定义：多条看似独立的旅程线并行推进，在卷末 / 书末汇聚到同一个高潮点。

诡秘之主第一卷实例：

```text
明线（主角视角）：
  日常值夜者 → 学占卜 → 调查连环凶案 → 发现线索 → 追踪

暗线（因斯·赞格威尔）：
  携0-08逃亡 → 设计陷害 → 引开强者 → 制造混乱

设定线（塔罗会铺垫）：
  第一次聚会 → 成员试探 → 各自任务

三线在卷末收束：队长牺牲、主角获得封印物、0-08 真相揭露
```

使用场景：悬疑、多势力博弈、复杂世界观。

智能体使用法则：
- 明线（主角视角）必须占 70% 以上篇幅。
- 暗线每次出现不超过 500 字，一章最多出现 1 次暗线片段。
- 收束前 5-10 章开始，暗线频率逐渐增加，制造风雨欲来的节奏。
- 收束点必须由主角的主动行动触发。
- 常见错误：暗线比明线好看，或收束时主角变旁观者。

## 三、模式选择与组合

### 3.1 当前写什么，首选什么模式

| 任务 | 首选模式 | 辅选模式 | 注意 |
|---|---|---|---|
| 新舞台开篇，主角刚进城 / 进学院 | 套娃嵌套 | 分形自相似 | 先建立日常，再嵌入第一个小旅程 |
| 主角突破 / 升级 / 收服重要资源 | 升级螺旋 | 链式咬合 | 突破方式必须和上次不同 |
| 长线目标的中间推进章 | 主线-副本 | 套娃嵌套 | 副本必须有独立爽点，不能纯铺垫 |
| 卷末高潮 / 大事件 | 多线收束 | 升级螺旋 | 收束前检查各线状态是否到位 |
| 卷与卷衔接 | 链式咬合 | — | 上一卷回报必须是下一卷入场券 |
| 日常 / 过渡章 | 分形自相似 | — | 过渡章也要有微考验 → 微回报 |

### 3.2 多层同时运行的典型组合

以斗破苍穹迦南学院卷为例：

```text
全书层（主线-副本）：
  主旅程“三年之约”仍在推进，迦南学院整个卷是一个大副本

卷层（套娃嵌套）：
  卷旅程“征服迦南学院”的考验阶段，嵌套多个小旅程

弧线层（升级螺旋）：
  收服陨落心炎 = 异火收服螺旋的第二次迭代

章层（分形自相似）：
  每章的节奏 DNA = 目标 → 被压 → 突破 → 打脸 → 新目标

卷末衔接（链式咬合）：
  陨落心炎的回报（斗王实力）→ 链式咬合到云岚宗之战（三年之约兑现）
```

### 3.3 模式组合检查三问

写任何关键章节前，必须回答：

1. 这一章在卷旅程的哪个阶段？
   - 门槛 / 考验 / 接近洞穴 / 磨难 / 回报？

2. 这一章内部用什么嵌套模式？
   - 是小旅程起点 / 中段 / 终点？
   - 还是螺旋某一次迭代？

3. 这一章的回报将咬合到哪个后续旅程？
   - 如何成为下一个旅程的燃料？

三个问题都能回答清楚，章节不会飘。只关注“这章有没有爽点”而回答不了这三个问题，章节就是孤立的，没有嵌套。

## 四、僵硬应用的 10 个危险信号

| # | 危险信号 | 问题本质 | 修正方向 |
|---|---|---|---|
| 1 | 每章开头都是“新的一天开始了” | 把平凡世界机械放在每章开头 | 直接从异常状态切入，上一章钩子就是本章入口 |
| 2 | 主角每章都要“犹豫一下”才行动 | 机械插入拒绝召唤 | 主角永远在行动，犹豫只在卷级接近洞穴阶段出现一次 |
| 3 | 章的磨难和回报之间有“然后他休息了一下” | 不知道回报应紧贴磨难 | 磨难和回报之间不能有缓冲段落 |
| 4 | 导师每章都出来说一段话 | 把遇见导师当每章必备元素 | 导师只在关键节点出现，日常信息由系统 / 环境 / 事件提供 |
| 5 | 每章末尾都断在“突然，门开了” | 误以为钩子只有生死关头一种 | 钩子分信息钩、事件钩、生死钩，必须交替使用 |
| 6 | 连续 3 章用同一个模式结构 | 不懂模式需要变奏 | 改变对手 / 方式 / 回报类型 |
| 7 | 大旅程磨难阶段写 5 章还没出结果 | 跨章磨难超过 2 章红线 | 拆成多个小磨难-小回报循环，或压缩到 2 章内 |
| 8 | 卷末高潮被盟友抢最后一击 | 主角打脸权让渡给配角 | 核心回报永远属于主角本人，盟友可助攻不能收割 |
| 9 | 卷与卷之间主角“回老家休息几天” | 没有链式咬合 | 上一卷回报立刻触发下一卷召唤，中间不许空转 |
| 10 | 信息揭露章一次性倒出 5 个新设定 | 把信息源当设定展览 | 信息分层释放，每层后紧跟主角反应 / 决策 |

## 五、智能体写作检查清单

### 5.1 写前检查：落笔前 3 问

- [ ] 这一章在哪一层旅程的哪个阶段？标出：场景 / 章 / 弧线 / 卷 / 全书 × 阶段名。
- [ ] 这一章内部将使用哪种嵌套模式？套娃 / 分形 / 链式 / 主线副本 / 螺旋 / 收束。
- [ ] 这一章的回报将咬合到哪个后续节点？

### 5.2 写中检查

- [ ] 主角是在主动推进还是被动响应？被动超过 40% 需调整。
- [ ] 当前段落情绪方向是什么？连续 500 字无情绪变化，插入微节拍。
- [ ] 如果有暗线 / 配角线，是否超过总篇幅 30%？

### 5.3 写后检查

- [ ] 本章爽点类型是什么？数值 / 打脸 / 战利品 / 信息 / 声望，至少一个。
- [ ] 爽点是否在本章内闭环？不能纯靠钩子延后。
- [ ] 主角亲自收割核心回报了吗？不能被配角 / 系统代劳。
- [ ] 本章新钩子是否同时满足：本章自然结果；引入新变量；不是重复上一章钩子类型。
- [ ] 如果这是连续第 3 章使用同一种嵌套模式，是否需要变奏？

### 5.4 跨章检查：每 5 章

- [ ] 这 5 章的嵌套模式是否有变化？不能连续 5 章都是套娃嵌套。
- [ ] 每个配角是否有独立动机？不只是“帮主角”。
- [ ] 反派被打脸后是否有实质性升级？
- [ ] 是否有超过 5 章的未回收伏笔？
- [ ] 主角在当前卷旅程中的阶段位置是否清晰可辨？

## 六、斗破苍穹前三卷嵌套拆解

       ├─ 跨越门槛（4-10章）：药老现身 + “莫欺少年穷”三年之约
       ├─ 考验阶段（11-40章）——内部嵌套：
       │    ├─ 套娃小旅程1：坊市卖药赚钱（召唤→考验→回报：第一桶金）
       │    ├─ 套娃小旅程2：魔兽山脉试炼（召唤→考验→磨难→回报：飞行斗技）
       │    └─ 套娃小旅程3：塔戈尔沙漠寻异火（召唤→考验→磨难→回报：青莲地心火）
       ├─ 接近洞穴（41-45章）：得知炼药师大赛，准备前往

### 第二卷：炼药师大赛 → 大斗师（约 51-100 章）

```text
卷旅程：从无名小卒到炼药师大会冠军
  ├─ 召唤：异火气息被炼药师公会察觉
  ├─ 考验阶段——内部嵌套：
  │    ├─ 套娃小旅程1：初赛突围（被质疑→展现实力→初赛通过→公会态度转变）
  │    └─ 套娃小旅程2：决赛对抗出云帝国（被压制→底牌尽出→夺冠→收服陨落心炎线索）
  ├─ 磨难（升级螺旋·异火收服第2次迭代）：
  │    对抗韩枫 + 吞噬陨落心炎（方法=战斗，代价=重伤，回报=斗王）
  └─ 回报：炼药师身份确立 + 实力暴涨 + 链式咬合→云岚宗
```

### 第三卷：云岚宗之战（约 101-150 章）

```text
卷旅程：三年之约兑现 + 发现新敌人
  ├─ 召唤：三年期满，上云岚宗
  ├─ 考验阶段——内部嵌套：
  │    ├─ 套娃小旅程1：击败纳兰嫣然（兑现三年之约）
  │    ├─ 套娃小旅程2：云岚宗长老车轮战（被压制→逐个击破→身份暴露）
  │    └─ 套娃小旅程3：药老被抓（最大的磨难——不是战斗失败，是失去导师）
  ├─ 磨难：与云山决战 + 药老被魂殿抓走
  ├─ 回报：云岚宗覆灭 + 实力突破斗皇
  └─ 链式咬合→新主旅程：营救药老 + 对抗魂殿
```

关键观察：第三卷的磨难不再是“差点打输”，而是“打赢了但失去了最重要的导师”。这是磨难变奏。如果每卷磨难都是“差点打死但反杀”，读者会疲劳。

## 九、硬性禁令

- 禁止每章机械填英雄之旅格子。
- 禁止把“平凡世界 / 拒绝召唤 / 遇见导师”当每章必备流程。
- 禁止用“休息几天 / 新的一天 / 忽然门开了”偷懒断章。
- 禁止让配角或系统代收核心回报。
- 禁止连续 3 章同模式不变奏。
- 禁止副本和主线无关。
- 禁止卷与卷之间空转。
- 禁止信息揭露章一次性倒设定。
- 禁止暗线抢走明线风头。

## 十、最终自检

交付前内部检查：

1. 这章 / 这弧 / 这卷是否处在五层旅程的明确位置？
2. 使用的是哪一种或哪几种嵌套模式？
3. 小回报是否成为大旅程燃料？
4. 上一节点和下一节点是否链式咬合？
5. 主角是否主动触发关键转折？
6. 爽点是否本章内闭环，而不是全靠延后？
7. 是否存在 10 个危险信号之一？如有，先修再交付。
8. 章内 1-3 个小阶段是否各自有：压力入场、三方利益、反派误判、加码、主角破局、小回报 / 新钩子。
9. 小阶段是否做了变奏：第三方类型、压迫方式、主角动作、回报类型不能连续重复。
10. 反派加码是否是真加码：损失扩大、时间压缩、退路减少、规则锁死、第三方表态等至少占一个。

一句话总纲：模板是死的，嵌套是活的。写出好章节的前提不是把六个格子填满，而是理解这一章在大大小小五个齿轮中的位置，然后让它在自己的轨道上自己转起来。
